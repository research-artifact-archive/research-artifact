# Compact competitive synthesis for partial repair

This supplement concerns one partial-repair job, fixed repeatable write footprints, complete re-preparation after rejection, a call cap q and declared common publication cost mu. It is separate from the main manuscript's whole-kernel universal-optimum theorem. See the [model](evidence/RESUMED_20260910_0343/partial_repair_baseline_01/PROOF.md), [compact proof](evidence/RESUMED_20260910_0343/partial_repair_compact_01/PROOF.md), [monotone acceleration](evidence/RESUMED_20260910_0343/partial_repair_compact_01/MONOTONE_PROOF.md), and [full study report](evidence/RESUMED_20260910_0343/partial_repair_compact_01/REPORT.md).

The controller observes a dirty set and may accept with protected repair or reject and reprepare outside. It never receives the write budget. Minimum consistent write expenditure adds across rejected intervals; with supplied cover/weight profile H,G, the worst consistent acceptance ratio is (mu+w(D))/(mu+G(floor((e+c(D))/q))). The returned exact threshold minimizes worst ratio against the budget-informed minimum worst cost. This objective does not restore simultaneous budgetwise optimality, which the earlier counterexample disproves.

## Use the singleton compiler

The two preserved implementation modules are in `evidence/RESUMED_20260910_0343/partial_repair_compact_01/`. For singleton footprints, the following example returns optimal ratio3/2, an upper feasibility path and a matching adversarial history:

```sh
PYTHONPATH=charged/evidence/RESUMED_20260910_0343/partial_repair_compact_01 python3 -B - <<'PYTHON'
from compact01 import singleton_profile, policy_accept
from compact02 import compile_profile, check_certificate
weights=[1,1,1];mu=2;q=3
H,G,order=singleton_profile(weights)
result=compile_profile(H,G,mu,q,sum(weights))
check_certificate(H,G,mu,q,sum(weights),result)
print(result)
# At e=0, a one-component dirty observation costs3 versus comparator2.
print(policy_accept(1,1,0,G,mu,q,result['ratio']))
PYTHON
```

For a runtime singleton dirty set, use its total scaled weight and cardinality as the first two predicate arguments. Update e by that cardinality only after a rejected observation and re-preparation. Keep the original q in all denominator lookups. Read/validate the full observation representation; a caller must not invent an expenditure or insert an observation after the policy has already accepted. Rational weights/mu can be converted exactly with `compact01.scale`; floats are not recommended.

The general compiler retains missing/nonmonotone profiles using its linear test. Correct arbitrary-footprint H/G and minimum-cover queries may require exponential work. For singleton profiles, sorting plus denominator-bucket feasibility yields the arithmetic bound in MONOTONE_PROOF.md. Exact integer encoding costs remain explicit. Generic minimax DP/information states are inherited, including [Dave, Venkatesh and Malikopoulos, Definition1/Theorem1](https://arxiv.org/pdf/2301.05089v2); literature-wide priority, application prevalence, native additive repair costs and publication-baseline calibration remain unestablished.
