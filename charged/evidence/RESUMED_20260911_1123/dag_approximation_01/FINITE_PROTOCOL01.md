Frozen before any new execution of this check, 2026-09-11. Exploratory arithmetic/model corroboration of PROOF01, not a general-program proof or a native performance evaluation. The formula and geometric family were derived before this protocol; this is not a preregistered discovery claim.

Enumerate every n=1..4, every edge subset of pairs i<j (all index-ordered DAGs, without deduplication), weights in {1,2,4}^n, and r=0,1,2. For each root evaluate every integer B=0..n+r. Keep every row, including violations and exceptions. No exclusions, retries or range extension after results. Upper runtime cap 300 seconds. Timeout/incomplete is retained as such, not success.

An explicit memoized completion-game explorer maximizes over every ready caller action and every feasible comparison result, using immediate preparation, cheap calls before r failures, and only exact-filter-admitted fresh/cached calls thereafter. It directly accumulates kernel work, protected work and public calls. A separate fixed minimum-ready, all-cached-suffix caller supplies a reference curve; its exact independent-job curve is inherited, not a new theorem. Maximizing caller choices for each B is allowed for the universal-caller upper audit: every resulting finite path can extend to a causal B-unaware caller by using safe cached actions elsewhere. It does not assert a common worst caller across B or compute the full V_r optimum.

The full-program lower itself is an analytic obligation, audited separately; this small explorer does not represent retained guards or free inspections.
