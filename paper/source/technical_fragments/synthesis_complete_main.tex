\begin{proof}
\emph{Coverage.} Initialization/discovery queues every new safe non-goal in $\mathsf{Open}$. Only expansion removes it, after querying all UC candidates. At quiescence, expansion/retries advance a finite control cursor and retain every nonwinner with candidates left in $\mathsf{Retry}$; promotion removes only winners. Thus all expanded states have complete UC outcomes, unfinished quiescent nonwinners remain retryable, and unexpanded safe non-goals remain open.

\emph{Termination.} Each state is expanded/promoted once and each candidate queried once. Reverse incidences are processed on promotion, so the finite search terminates.

\emph{Soundness.} Goals start at rank zero with compatible handover states. By induction, each promotion adds a safe state above a complete nonempty proving set of previously ranked winners: every UC successor, or every outcome of one control event. Queried buckets are immutable. Extraction retains all UC events, chooses one such control bucket at quiescence, and disables other controls. Every reached non-goal is safe, has a successor, and every successor has strictly smaller natural-number rank. Consequently no maximal run is an infinite run or a non-goal deadlock, and every run reaches a matching quiescent goal. The monitor rules advance exactly the memories active over each event; induction from entry establishes every declared safety interval. Handover retains the matching new memories.

\emph{Completeness.} At failure both exploration queues are empty and promotion has reached a fixed point. Some entry is in $L=V\setminus W$, and $L$ contains no goal. Coverage ensures that each safe state in $L$ was expanded. If it is UC-enabled, at least one UC outcome lies in $L$, since otherwise it would be promoted. At quiescence every control candidate is exhausted; each enabled control bucket has an outcome in $L$ for the same reason. Against any history-dependent policy the environment can select such an outcome after every history. Disabling all events deadlocks; otherwise the resulting run reaches an unsafe state or stays outside the goals forever. Hence no winning policy covers that entry. A winning policy therefore rules out failure and, by termination, forces success. Finally, UC priority loses no winning policy: removing optional controls at a UC-enabled state removes runs without introducing a deadlock, and the restricted policy remains admissible in the original game.
\end{proof}
