\subsection{Independent-update construction}
For $n\geq1$, take $n$ components, each with one old and one new state and a singleton transfer. Every version and its endpoint controller admit a controllable $tick$ self-loop, making both endpoints deadlock-free. There are no monitors, dependencies or uncontrollables; the unique new endpoint is available for handover. These inputs are eligible. Each update state is the subset of transferred components, and all $2^n$ subsets are reachable; Direct-Full discovers them all.

Under Lazy's default order, pending transfers precede ordinary events in this family, so expansion follows one $n$-step chain. Because $\mathsf{Open}$ precedes $\mathsf{Retry}$, it reaches the sole goal after discovering exactly $n+1$ states. Backward propagation then assigns ranks $0,\ldots,n$ and proves the entry state before any alternative query. The ordinary self-loops are losing choices under finite completion; both methods use the same terminal goal. Thus the separation concerns exploration of one supplied game.
