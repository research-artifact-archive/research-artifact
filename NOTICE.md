# Rights and provenance

This release applies the repository's MIT distribution policy to the original research implementation, authored inputs, and accompanying documentation. The copyright holder is identified anonymously for review. The license does not relicense external work cited by these materials.

Third-party article PDFs, workstation runtime binaries, upstream source copies, private author/assistant correspondence, and machine-specific paths are not included in the frozen package. `package/PROVENANCE.json` identifies copied material, literal path projections, and excluded source files with available hashes and dispositions. References to an excluded file are evidence of its recorded provenance, not a claim that the file is redistributed or independently rebuilt here. Java compilation uses the reviewer's separately installed JDK; the original recorded JDK binary was not independently rebuilt from the cited upstream source.

Path projections are derivative distribution documents. They are not original preregistrations. `package/ALIASES.json` describes byte-identical files stored under a canonical path; it does not remove any outcome units. All earlier failures, timeouts, invalid outcomes, and unstarted units retain their original status. The old repository content remains in Git history; the current tree concerns the retry-policy paper.

AI assistance was used in author-side research, implementation, analysis, and writing. The authors remain responsible for the claims and checks. See the paper's Methods disclosure; assistant checks are not independent blind certification and no human-subject evaluation is represented.
