These PDFs are the current pre-submission main/supplement snapshots supplied with this artifact update. The manuscript anticipates a final `fse27-submission` tag; that tag has not been created for this update. Use this repository commit as the current immutable version. They are distinct from ongoing alternative editorial drafts. `source/build/generated/` contains table/figure inputs and scripts' saved outputs, including the fixed 135-cell table and ext1–7 summaries. Private author notes, candidate reviews and submission instructions are excluded.

The source uses XeLaTeX/acmart and multiple project files. Building the Java tool or running the saved-evidence checks does not require a TeX installation. Consult `source/latexmkrc` for the recorded paper build configuration.
