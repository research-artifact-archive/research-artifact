# Development01: fixed value and certificate checks

Before first oracle result, freeze all source modules, this plan, the input list,
and full unit order. Reuse all4,232 final semantic inputs at budgets0..4; expected
excess values come from saved primitive/scalar roots after subtracting normal
work. Add96 previously authored relabel/wide-premium B1 cases at budgets0/1/2/4/8
using independent scalar evaluation. Add the four-job family under six premium
scales at six budgets chosen before new oracle outcomes; include zero/empty
controls. These are known-input regression and explicitly authored extension,
not an application population or new fixed final evaluation.

Each unit has5seconds; the run has180seconds. It serializes and reloads every
certificate before checking and compares the returned value with an independent
scalar or the existing unchanged all-budget compiler/checker. Scalar is used for
budgets<=32; all-budget encoded values supply larger-budget expected answers.
Input-family scales vary premiums alone, not homogeneous total-price scaling.
This may or may not improve oracle cost. Keep all statuses and no retries.

Malformed controls are derived from one fixed general non-cost-compatible family
certificate with all p>0 and B2 (its root value is already known). Reject value,
peak, missing-node, extra-node, budget, input-edge, bound/packed and schema faults
when structurally applicable. The checker must reject rather than normalize
malformed certificates. Generated control identities/counts are recorded before
checking mutated outputs; structural inapplicability is explicitly counted.
