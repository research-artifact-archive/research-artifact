# Charged-call anonymous paper

`main.pdf` is the research revision *Compiling Optimal Retry Policies with Charged Atomic Calls*. It has 18 pages through the complete Conclusion and 20 pages including Data Availability and references. `SNAPSHOT.json` records the exact PDF/source hashes and the immutable evidence commit cited by the paper.

The charged revision adds a three-mode atomic-call normal form, original-price actual-write correspondence, two supporting slopes per job, a mixed-price reduction to checked cursor policies, and source-derived Deephaven experiments. The [research-lineage table](../charged/RESEARCH_LINEAGE.md) distinguishes these extensions from reused zero-fee results, including the same restricted hardness theorem, concave floor/cap lemma, and two-fee ordering/packing. The preceding zero-fee paper remains unchanged under `../package/paper/`; its later publication revision remains in Git history.

To build locally, install an ACM `acmart` LaTeX environment with `pgfplots` and run `pdflatex -interaction=nonstopmode -halt-on-error main.tex` twice in a copy of this directory. The archived class hash is recorded. TeX installation differences and timestamps can change PDF bytes. Class files and font/runtime installations are not redistributed.
