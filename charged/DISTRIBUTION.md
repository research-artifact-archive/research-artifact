# Distribution and provenance

This charged supplement adds new research evidence to the earlier public zero-fee release. It preserves the earlier package and Git history. Full status partitions, unsuccessful conjectures, checker defects and failed calibration remain visible; reproduction does not change their original status or create new evaluation samples.

`PROVENANCE.json` maps each distributed evidence file to its source-relative path, original byte size/hash, public byte size/hash and any literal author-path projection. The two oversized `UNITS.json` ledgers are stored as deterministic gzip with a logical path and decoded byte size/hash. Decompression reproduces the complete anonymized ledger; it does not reconstruct a different input population. A public file's digest need not equal the original digest when an explicitly recorded path projection occurred. Original manifests retain their original recorded digests.

Historical experiment drivers include their original deadlines, absolute paths and append-only output rules. Run the portable public entry points instead of editing and rerunning those historical drivers in place. Referenced external runtime/source/article paths are provenance records, not claims that those files are bundled. No downloaded JDK, source archive, Maven/Gradle cache, private author/assistant correspondence or external article PDF is distributed.
