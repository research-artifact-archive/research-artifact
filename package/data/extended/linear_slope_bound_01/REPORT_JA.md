# 入力コストの支持直線による線形区間数上界

著者側の導出と別担当の証明・コード検討は、各残余問題の整数予算上の値が「0と残余仕事の失敗コスト」を傾きとする直線の下包絡で表せることを支持した。異なる正のコストがd種類なら、整数点間を結ぶ際の橋渡しを含めても正の傾き区間は2d以下。鎖 c_k=3^k, p_k=5*3^(k-1) で2nに達する。全upset表の区間数は(n+1)2^n以下となり、既存の構築・検査は2^n poly(入力bit数)。幅が固定なら鎖prefix数により多項式、幅パラメータではXPでありFPTとは主張しない。

結果前に固定した22,077 unitsは全てSUCCESS。FAILURE/TIMEOUT/INVALID/NOT_RUNは各0、総9.070424秒だった。
