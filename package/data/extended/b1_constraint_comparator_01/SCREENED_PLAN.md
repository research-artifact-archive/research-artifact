# Stronger B1 DP extension

This extension is planned after observing CP-SAT complete the fixed comparison and simple DP/all-budget timeouts. It does not revise the234 frozen units or their outcomes. The78 input roots remain known, and no held-out claim applies. New implementation bytes are fixed before their own conformance/timing results.

Use the inherited B1 allocation lower bound L(S)=max_{i in S} min(c_i,p_i). A fixed topological order has exact B1 value from a backward recurrence f=min(p_i+child,max(c_i,child)); retain the entire no-failure certificate. Use two feasible incumbent orders: smallest available c and smallest available ID. If L=incumbent, close without state expansion. Otherwise evaluate every available protected action and only the cheapest available FAST action, using the already proved cheapest-fast dominance. A candidate lower bound p_i+L(child) or max(c_i,L(child)) >= incumbent may be skipped. Every improvement records the exact child's certificate. The recursion strictly removes a job; memoization is exact. Bounds, mode choices and scan do not depend on benchmark outcome labels.

The lower bound follows by targeting one job with the sole failure; either its protection premium is paid or its failure cost is paid. Feasible fixed-order incumbents are upper bounds, and replacing a child by a lower bound can only lower an action value. Hence pruning cannot remove an improving optimum. This is an implementation of inherited bounds/dominance, not a new mathematical contribution.
