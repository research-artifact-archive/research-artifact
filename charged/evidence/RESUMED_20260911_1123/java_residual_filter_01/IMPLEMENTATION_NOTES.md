# Implementation and integration boundary

The adopted implementation is **v2/ResidualFilter.java**. The top-level ResidualFilter.java is the immutable tested first version with PriorityQueue; do not compile both classes together. Revision02 replaces its possible linear backing-array resize with linked complete binary heaps. attempt01 and attempt02 are different versions, not independent workload populations.

## State and complexity argument
Let high contain the largest min(k,|D|) completed weights and low the rest; high is a min-heap, low a max-heap. topSum is high's sum, ell the incurred protected body work. The constructor inserts only supplied COMPLETED weights and rejects ell>topSum. Initialization is O(|D| log(|D|+1)), storage O(|D|). The current job's weight is passed by value and not retained by permitsFresh. It enters the heaps only in recordCompletion. No job ID, remaining job, total job count, edge, B, actual write counter, body-work diagnostic or full charge enters the filter.

For k=0 the prospective top sum is zero. With fewer than k completed high entries it is topSum+w. Otherwise it is topSum+max(0,w-min(high)). The query checks ell+w against this sum with a constant number of long operations and root accesses. For a mismatch, the poststate top-(k+1) sum is topSum+max(w,max(low)), taking max(empty)=0. The update first preflights the new k,ell,top sum and completed count without mutation; then promotes at most one old low entry and inserts w. Match/fresh only insert w. Each insertion/removal on a complete linked heap follows a binary-index path and a sift path of length O(log(|D|+1)); there are a constant number of such operations per completion. This is an abstract pointer/comparison-operation guarantee, not a bound on Java allocation/GC or elapsed time.

Nonpositive weights, negative initial k/ell, null constructor input/outcome, nonviable initial ell and unsafe fresh are invalid; representability overflow throws ArithmeticException. Nonnegative long sums and ell+w must be representable even where a mathematical unbounded-integer implementation could decide without storing that sum. Rejection is not a verdict that the unbounded mathematical state is unsafe. Validation and arithmetic overflow precede mathematical-state mutation. OutOfMemoryError or other VM/resource failures have no rollback guarantee. The filter is single-owner and not thread-safe. Caller supplies sound readiness, fixed weight, truthful outcome and exactly-once completion; it cannot detect duplicate job identities because it stores no identities.

k>|D| is deliberately allowed in this BODY-only component. The charged fee-separation theorem assumes k<=|D| and is not generalized by these tests. No heterogeneous p/h/q API is implemented. Common-fee algebra belongs to PROOF03, not to a native accounting claim here.

## Per-key wrapper adaptation
NativeIntegration.java adapts the existing UniversalCallbacks.java current-capture / validation-only-compute / cached-compute pattern. It adds fresh-compute, a captured immutable saved-parent list and the residual filter. It does not compile or patch the predecessor. All three foreground wrappers use ConcurrentHashMap.compute. Inputs are permanent non-null identity objects with final primitive fields; keys have stable equals/hashCode; all writers preserve keys and publish a fresh object. pureKernel uses only captured own input and List.copyOf(saved parents), returns a deterministic wrapped-long payload, and performs exactly w recurrence steps. It does not read a live map or diagnostics. Wrapper instrumentation records the completed body invocation afterwards. Preparation is paid on both match and mismatch; fresh has no preparation.

An external executor commits gate writes and the controller waits for that write operation to finish. ActualExternalWrites increments after the publication returns. Cached exposes its comparison Boolean; cheap returns success/failure; fresh returns its output. The Controller sees declared current weight and these wrapper outcomes. Only ResidualFilter.recordCompletion receives their derived outcome; it receives no diagnostic measurements. Cheap successes are recorded as MATCH even before the r-failure switch, so their weights remain in D. Failed cheap attempts are never inserted. The allcached comparator uses exactly the same cheap phase and no filter decisions. Allfresh begins protected immediately and is not required to meet the optimal L curve at B=0.

The callback output is saved rather than reading the live map for completion. The postwrite boundary publishes after compute returns and BEFORE saving that returned output, so later bodies must use the saved parent's old output although its map entry has changed. This is not a test of the JDK's internal postpublication/pre-return interval. The doublewrite boundary uses two actual external assignments for one observed mismatch and tests that the filter's k still increments by one. Raw diagnostic and control data are in attempt02/native.jsonl; DIAGNOSTICS_FROM_NATIVE.jsonl and CONTROL_FROM_NATIVE.jsonl are separately extracted views of those same Java records, not extra executions.

## Scope of the operational evidence
Fixed native input validation bounds n<=6, 1<=w<=100 and r<=2, making all body counters and filter sums representable. This is a minimal whole-kernel arithmetic example, not an application client. Parent capture/folding, allocation, comparison, map traversal, writer work, filter maintenance and waiting are not charged by the declared body metric; no full runtime cost is erased or called measured. No latency clocks are supplied to the controller or reported as performance evidence. Source-level correspondence is conditional on the Java API and pinned implementation premises; the local OpenJDK17.0.19 src.zip is hash-bound and its compute documentation/source excerpt is saved. Finite traces do not prove JMM correctness, termination under arbitrary scheduling, concurrent resize, tree-bin behavior, arbitrary external interleavings, or real-client importance. Constant-hash tests here contain at most six keys and do not exercise tree bins.
