# Exact common-policy feasibility by accumulated-cost thresholds

Use the positive-toll DAG interface and the supplied-budget comparator K already defined. Let E=Sigma+r max sigma_i and M=n kappa+sum W_i. K(b)=M for every b>=E. e is the minimum footprint count consistent with the observed history, clipped to E. Preparation resets the entire attempted job after each rejection. Let a be total cost paid before the next attempt, S the unfinished jobs, and t the remaining rejection allowance.

At terminal S=empty define Theta(empty,t,e)=K(e). At any other state let e_D=min(e+c(D),E), and define

Theta(S,t,e) = max_{ready i} min_{D observable for i} max( Theta(S-i,t,e_D)-kappa-w_i(D), Theta(S,t-1,e_D)-kappa if t>0 ).

The absent rejection alternative is negative infinity, not zero. Each recursive child strictly decreases |S|+t. All quantities can be exact integers after common scaling. Theta is the greatest permitted prefix cost a for which some continuation satisfies total cost<=K(total least-consistent writes) on every terminal observation history. This is proved by induction: terminal feasibility is the downward interval a<=K(e); acceptance and rejection shift child intervals by their costs; the controller's choice after D unions downward intervals (maximum endpoint); the environment's choice intersects them (minimum); choice of ready job unions them again (maximum). Thus no exchange of quantifiers or observation-before-job-choice assumption occurs.

Terminal comparison at the least-consistent count is necessary because minimum-cost footprint words realize each interval independently, and sufficient because K is nondecreasing. Clipping after E is valid by saturation, even when partial observations require more writes than full saturation. Therefore one initial common optimum exists iff Theta(J,r,0)>=0. It can be realized without receiving B: select a maximizing ready job, observe D, and accept when a+kappa+w(D)<=Theta(S-i,t,e_D); otherwise choose the feasible rejection. A universal common optimum must be a member of the supplied-budget comparator class at every B, so the upper guarantee is exact equality in worst case.

For a fixed minimum footprint count c, only maximum attainable damage H_i(c) needs to be included in the constructor's adversarial alternatives. The two child states depend on c, while only acceptance subtracts damage; increasing damage cannot improve feasibility. At most m_i+1 counts are possible, including clean c=0. Runtime must still compute the minimum count c(D), not the actual hidden number of writes. Arbitrary footprint profiling and minimum cover can be expensive; singleton footprints make c(D)=|D| and use sorted-prefix work. No inexpensive preprocessing is claimed for arbitrary families.

Given correct profiles and the root comparator curve, a full threshold table contains at most I(r+1)(E+1) entries, with I reachable unfinished sets. With h=max_i(m_i+1), time is O(I n(r+1)(E+1)h) arithmetic operations, plus cost encoding, and memory O(I(r+1)(E+1)) beyond inputs/actions. Fixed-order jobs have I=n+1 and one ready choice per state. This eliminates enumeration of accumulated cost and its subset sums, not arbitrary-DAG ideals or binary-encoded r. Computing the comparator requires a separate finite-budget game up to E. The algorithm is a specialized application of finite minimax and downward-closed viability, not a claim that dynamic programming or information states are new.
