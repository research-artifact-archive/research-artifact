# Retry-policy research artifact, local version 5

This is an author research package, not a public release or independently certified submission artifact. The paper remains an unclosed research draft. No claim of application prevalence or elapsed-time improvement is established. All inputs are authored; no human evaluation was performed. See the paper's Methods paragraph for AI assistance.

Version 5 preserves the version-4 source/data tree and entry points, adds the arbitrary fixed-order persistent compiler, its two certificate checkers, the integrated dispatcher, paired-chain hardness checks and the later general-checker pipeline. Earlier top-level metadata is in `history/v4/`. `PROVENANCE.json` records exact copies, literal workstation-path projections and excluded source files. Projections are derivative documents, not original preregistrations. Prior unfavorable outcomes remain in the package. The original source files and earlier archives were not edited.

Some byte-identical JSON files from the second persistent-checker experiment are stored once. `ALIASES.json` maps every absent logical file to its canonical exact bytes, original hash and size. `reproduce_latest.py` resolves these aliases. This deduplicates repeated artifacts and input files; it does not remove outcome rows. Original machine paths, assistant raw reports, rendered images, third-party source copies and articles are not redistributed here; their source hashes and dispositions are retained where relevant.

Use assertions-enabled Python 3.10 or later (the latest recorded replay uses 3.12.14). All output directories must be outside the package and must not already exist. No package installation or network access is needed for the latest stages:

```sh
python3 -B reproduce_latest.py verify --out ../verify-v5
python3 -B reproduce_latest.py all --quick --out ../smoke-v5
python3 -B reproduce_latest.py all --out ../replay-v5
```

Modes `fixed`, `fixed_controls`, `shared`, `paired`, `integration`, `scale`, and `pipeline` run one stage. Full replay checks 88,830 retained units: 24,029 fixed-order semantics, 63 malformed-input/certificate controls, 44,838 shared-checker cases and controls, 19,786 paired-chain reductions, 15 dispatch/scope controls, 54 saved successful persistent-scale certificates and 45 saved successful general-pipeline certificates. Quick mode samples only semantic/reduction stages and must not be described as full replay. Scale and pipeline modes verify every original outcome count and all saved persistent construction hashes, then check saved successful certificates; they do not rerun the original timeout experiments or produce new performance samples. Replay results do not enlarge the scientific denominators.

The earlier entry points remain byte-identical: `reproduce.py`, `reproduce_extended.py`, `reproduce_oracle.py`, and `reproduce_current.py`. Their original commands, optional OR-Tools/Java requirements, evidence boundaries and earlier local validation results are described in `history/v4/README.md`, `history/v3/README.md` and `history/v2/README.md`. Existing Java stages require Java 17. Prior successful full replays are not new independent experiments.

To use the compiler on your own input, create a JSON object such as `{"cp":[[3,2],[1,4]],"edges":[[0,1]]}` and run:

```sh
python3 -B retry.py compile --input ../case.json --out ../controller.json
python3 -B retry.py check --artifact ../controller.json
python3 -B retry.py query --artifact ../controller.json --budgets 0 1 2 1000000000000
```

Compilation checks the emitted certificate before saving it and refuses to replace an existing output. An optional `--order ../order.json` supplies a JSON array of job IDs. Reports label a branching input with a supplied order as `SUPPLIED_SERIAL_ORDER_ONLY`; a unique order or the other exact routes use `GLOBAL_ADAPTIVE_RETRY_GAME`. Queries report residual work and total work for the convention that normal cost equals failure cost; for other normal costs, add their sum to the residual yourself. The API assumes the mathematical retry contract in the paper, not arbitrary concurrent programs. Checking arbitrary valid persistent artifacts can be slower than checking artifacts generated by this compiler.

`src/fixed_order_profile_03/dispatch.py` chooses cost-compatible packing first, then the persistent representation for a unique topological order, otherwise the general ideal compiler. The lower-level persistent constructor also accepts a supplied topological order: on a branching DAG this certifies the restricted serial order only, not global adaptive optimality. The checker certifies values/thresholds, not arbitrary claimed construction counters. Its generated-class logarithmic traversal bound relies on persistent shared subtrees; arbitrary semantically valid but differently shared certificates can take quadratic time. These scope distinctions are exercised by the integration stage.

The recorded evaluation has negative results: the older complete hybrid succeeds on 36/60 chains, persistent construction plus the first checker on 42/60, and the changed checker on 54/60, with respectively 24, 18 and 6 timeouts under the frozen limits. All 60 persistent constructions finish before their respective check outcomes. These versions use distinct runs; elapsed times are descriptive and are not a simultaneously randomized comparison. The general pipeline still has the same three construction timeouts. The paired-chain theorem is weak binary-price hardness, not strong hardness or a constant approximation gap. The application-source investigations remain partial or negative fits.

The later linear_slope_bound_01 extension establishes the author supporting-line invariant for this recurrence: at most 2d positive sampled runs for d distinct positive costs, tight at 2n on a chain; at most (n+1)2^n total entries over all residual subsets. It includes source-comparison limitations and the integer-versus-continuous maximum control. Replay its 22,077 retained units separately:

```sh
python3 -B reproduce_basis.py all --out ../basis-replay-v5
```

This covers 17,656 small envelopes (105,936 floor cells), 4,355 existing artifacts containing 128,116 stored curves, 64 tight chains and two controls. A supporting-line check is weaker than full Bellman/action-coverage checking; the four old scale checker timeouts remain timeouts. The two latest entry points together replay 110,907 retained units, with no scientific sample increase. An affine input-slope envelope and slope deduplication already occur in the different robust-optimization model of Bertsimas--Sim; this artifact makes no independent novelty or application-fit certification.
