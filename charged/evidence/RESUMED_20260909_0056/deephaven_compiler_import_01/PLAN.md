# Compact compiler-to-native policy import, development successor

This experiment changes the controller implementation from an in-Java scalar DP to serialized all-budget curves emitted by the existing paper compiler. The compiler and Bellman checker are exact byte copies of dependency_curves_01/curves.py and checker.py. The fixed input is the source-derived K->V chain with c=(4,176), p=lambda*c, lambda in{1,3,10}. Export does not receive B and must not iterate over B. Each JSON certificate is serialized, parsed afresh and checked on every nonnegative integer budget by the existing affine-partition Bellman checker. A simple text profile resource is bound to that exact certificate and consumed by Java. Schema, prices, mask set, profile shape and values must match the fixed resource manifest. Compilation/check/export costs and bytes are recorded, including initial construction. They are not merged with native selected-operation charges or treated as an application speedup.

The native denominator is63cells: the same seven already observed source/schedule fixtures and three lambda values, crossed with three new controllers. The first uses the compiler's existing default, protection on a value tie. The second prefers fast on a tie, matching the first Java-DP development protocol. Both must attain the same all-budget optimal cap, but their realized costs may differ. The third receives the same remaining B and chooses fast locally iff B<=lambda, otherwise protects. That policy is a simple same-information comparator. It does not evaluate downstream curves. No future writer actions are exposed to any controller.

The source checkout includes the separately recorded MAX-key progress repair; every primary row key is0..30, so this new branch is unreachable in these fixtures. Preserve the84 earlier scalar-DP/upstream/threshold/protected runs and their pre-repair source hashes. Current fixtures are observed inputs reused for integration and new-baseline comparison, not independent or held-out evidence. Do not pool them into a new deployment population. Any cross-packet comparison must disclose source/controller versions and tie rules.

Use the same real phase-sensitive update-graph driver, value-only source writes and exact changed columns, q bounds, return-value checks and resource counters. A controller can prevent later event-triggered writer actions; q is an upper bound. Java must make decisions from the imported all-budget profiles without constructing a B-sized DP table. Check huge-budget values separately at10^6,10^12,10^18 to test the finite profile interpretation without executing a huge replay. All actual native quotas remain0,2,4.

Falsifiers include wrong compiler/checker binding, invalid certificate, changed exported profile, incorrect policy decision, malformed native input, wrong output, quota or source-cap violation, failure to terminate, or a compiled trace whose charged cap exceeds its certified value. All63 cells remain in the denominator; FAILURE/TIMEOUT/INVALID/NOT_RUN are preserved. Wrapper180seconds and per-case bounds remain fixed. The Python trace checker is a separate author reconstruction; no universal native minimax equality, source proof by testing, production prevalence, CPU speedup or independent review is claimed.
