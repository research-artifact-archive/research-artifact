\paragraph{Obligations that begin at activation.}
\label{sec:activation-scoped}
\emph{Activation-scoped} interpretation ACT starts a pure invariant $\Box\varphi$ with the actual post-boundary observer vector, checking $\varphi$ there and after each later label. It retains factual fluent values, not a past-violation bit. Start follows the declared observer rules and is not consumed twice. This differs from A's safe-history restriction and H's whole-past obligation.

\begin{proposition}[Activation-scoped invariant initialization]
\label{prop:activation-scoped}
For such an invariant, let a safe reference history end at vector $v$. If the supplied initialized monitor has the same continuation language as that reference history's residual, it is exact for ACT at every activation with vector $v$, including activations whose actual histories violated the invariant before its start.
\end{proposition}
\begin{proof}
The safe reference prefix leaves only current/future invariant obligations. Deterministic observers give the same future valuations from $v$ on every common suffix, proving equality with ACT. Earlier violations in the actual history do not affect those valuations.
\end{proof}
This requires an appropriate initializer, not merely A inclusion. Section~\ref{sec:pc2-case} proves ACT directly for the thirteen invariants along the saved PC2 policy; the 138 A checks remain A checks.

\subsection{From a Safe Lookup Cell to an Activation-Scoped Invariant}
\label{ta:lookup-act}
Proposition~\ref{prop:lookup-act} in the main paper gives the criterion and complete proof: a faithful invariant monitor reached safely with observer vector $v$ accepts exactly $\operatorname{ACT}_\varphi(v)$. The witness may come from the unrestricted monitor--observer product; physical executability of that reference history is unnecessary. We first check the constructed lookup, then compare its monitors with source formulas, and finally identify the conditions required at actual activations. Main-paper Tables~\ref{tab:guarantee-evidence} and~\ref{tab:validation-populations} give the overall guarantee and validation maps.

\paragraph{Reconstructing the frontend lookup.}
The nine inherited inputs have 46 NEW requirement positions and three variants, yielding 138 occurrences. The saved independent reconstruction checks all 138 lookup tables and 1,587 entries, including 900 non-error entries, 687 error entries, 408 observer columns and 31,176 observer transitions. S4.2 gives the export protocol and reconstruction checks. A non-error entry is chosen from a pair reached by a finite safe word of the free monitor--observer product; equivalent-state alternatives must have the same error language. The reconstruction explores non-error successors, so induction on its search depth supplies that witness. The saved table records $(v,m)$, not the witness word itself.

\paragraph{Matching monitors to source invariants.}
The reconstruction establishes safe lookup reachability. To check the proposition's separate faithfulness premise, we compare the saved monitors with the original source invariants independently of the Java formula compiler. All 46 NEW positions are pure invariants $\Box\varphi$: seven use declared fluents only, six use action predicates only, and 33 use both. Names such as Pending and SEQUENTIAL designate deterministic current-value observers, not additional temporal operators. A restricted parser reads propositional negation, conjunction, disjunction and implication inside $\Box$, assertion aliases, fluent initial values, event-set aliases/differences and finite indexed ranges. Unsupported syntax is rejected. Source-defined observer rules must match the saved rules, including action predicates' last-event convention.

For each invariant, the finite check verifies $\varphi(v_0)$ and a non-error initial monitor state, then explores every non-error monitor--observer pair. At each pair $(m,v)$ and every checked label $a$, it verifies
\[
 \delta_M(m,a)\in\mathsf{Error}
 \quad\Longleftrightarrow\quad
 \neg\varphi(d(v,a)).
\]
The checked alphabet contains every saved observer label and every source-referenced event, plus a fresh representative for all unmentioned events. The latter class has the same source-observer effect (declared fluents stutter and action predicates reset); the saved DFA uses its default transition. From the initial pair, induction on word length now proves that a prefix is non-error exactly when all its source valuations satisfy $\varphi$. Thus this finite condition establishes the monitor-faithfulness premise used above on these alphabets; it is not an assumption that a passing table check alone validates the compiler.

All 138 occurrences pass: 900 non-error product pairs, 35,283 pair/label checks, and all 900 non-error lookup cells contained in the safe product. There are no unsupported formulas or mismatches. The three variants agree on source formula, observers and monitor for each of the 46 positions; the counts are occurrences, not 138 independent formulas. This establishes ACT exactness for those lookup cells under their reference observation semantics.

\paragraph{What this yields for a winning policy.}
At a real activation, the adapter must use this lookup entry for the actual post-start observer vector and must subsequently follow the same observation and update rules. Start is accounted for once, before initialization, rather than observed twice. Every active suffix of a winning policy is accepted by the installed monitor; the proposition therefore gives the invariant at activation and after every observed prefix. A previous actual violation is irrelevant to this explicitly start-scoped requirement. This is not the history-inclusive H interpretation, nor does it turn an arbitrary A inclusion into ACT exactness. An undefined/rejected lookup or a separate fallback initializer is outside this argument. Conversely, $\varphi(v)$ alone does not ensure that the table has a non-error entry for $v$.

\paragraph{Remaining activation conditions.}
Physical-state decoding, actual key selection and absence of fallback at every benchmark activation remain unchecked. In particular, the adapter preserves physical observers across commands, whereas an implicit action predicate can reset under the reference alphabet convention; matching future observations must be checked rather than inferred from table equality. The discrepancy is not shown to be conservative: the saved checks do not determine whether it rejects or admits additional actual activations. These results do not report 900 observed activation points or claim that all 25 WIN policies have newly validated source semantics.
