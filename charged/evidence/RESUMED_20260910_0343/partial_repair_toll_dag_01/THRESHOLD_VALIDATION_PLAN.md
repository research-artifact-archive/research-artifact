# Threshold certificate validation, fixed before execution

This is a new representation/checker test using already observed outcomes, not a new independent experimental population. Freeze hashes of run02 inputs/raw/summary, the threshold proof including HISTORY_COUNT_CORRECTION, constructor, checker and validation driver. For all 37,248 existing units, compare the threshold root with the saved quantified existence answer and stored known-budget curve. Keep every discrepancy. Count threshold states separately; do not treat the old outcomes as held out.

Add 240 fixed cases not previously executed: three-component weights (1,1,1) or (1,2,3), footprints {1,2,7} or {1,2,4,7}, paired with one component of weight1, both chain orders; r=0,1,2; toll=1/2,1,2,3,6; all quantities scaled by two. Exactly 2*2*2*3*5=120 cases (the initial 240 in this paragraph is an arithmetic slip corrected here before execution; use120). These expose histories whose least-consistent count exceeds the comparator saturation bound. Every dirty mask is independently enumerated by footprint words. Compare the constructor to full-observation known-budget DP and the accumulated-cost quantified policy game; export and independently check every certificate. Preserve all outcomes and four changed-certificate controls.

Also export/check the already observed two-job order pair and three-job chain(1,3,1), and exhaust all terminal observation words of each executable certificate that has a common optimum. The independent checker imports no constructor. It regenerates minimum footprint counts from input footprint words, computes the known-budget game from all masks, verifies every threshold equality/selected job against all observed dirty sets (not the compressed profile), and verifies that exported table dependencies are closed. Changed theta values, action job, comparator values, and clipped ceiling must reject. The root sign certifies mathematical feasibility only, not source semantics or third-party independence.

A 570-second campaign clock cap marks remaining units TIMEOUT. Retain SUCCESS/FAILURE/TIMEOUT/INVALID outcomes without exclusion or retry. This study makes no native/timing or application-prevalence claim. Peak memory is observed rather than enforced by macOS RLIMIT_AS. Weight encoding and profile construction costs are reported separately from the finite table bound.
