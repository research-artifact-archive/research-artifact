\paragraph{A source requirement constraining ordinary update actions.}
\label{sec:gsm-entry-derivation}
GSM changes decoding from mode 2 to mode 3. From every old entry, follow its cycle to the first received-message state; then stop the old requirement, start the new one, decode in mode 3, output and transfer at the sender state. The current action observer is zero at activation, so the saved lookup installs non-error state zero. The active new monitor rejects mode 2 while permitting mode 3 and output; transfer reaches the supplied endpoint's initial projection. These steps respect R1's ban on ordinary actions between stop and start. A decreasing rank bounds completion by twelve events (Proposition~\ref{prop:gsm-active-policy}, Technical Appendix~\ref{ta:activation_scope}). This analytical policy uses the existing source and lookup, not a new solver run. It establishes ACT over ordinary update behavior; the separate 45-pair source check establishes the interval's E initialization. Earlier mode-2 events still preclude a whole-history claim.
