Some duties depend on what happened before activation. The initialized monitor must then allow only continuations consistent with every admitted past. Technical Appendix~\ref{ta:residual_formal} formalizes this as residual inclusion: the initialized monitor's continuations must satisfy the requirement after every history in its declared scope. Equality gives an exact monitor; stricter inclusion can reject feasible updates. The scope must contain the actual histories, and an empty scope makes the inclusion vacuous.

The saved checks use safe pre-activation histories consistent with the current observation for new requirements and a reference beginning at entry for interval requirements. A whole-history interpretation also includes prior violations and is considered separately (S3).
