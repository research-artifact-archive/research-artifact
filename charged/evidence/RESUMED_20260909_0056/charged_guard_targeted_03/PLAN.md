# Targeted charged-guard falsification, exploratory successor03

Sixteen observed source inputs had26 root-optimal prepare/acquire actions whose forced immediate guard resolution was suboptimal, although a three-mode policy also attained each observed root value. This result-selected successor tests whether a small price perturbation breaks that equality. It does not reclassify the original observations as pre-registered or held out.

For every selected input, multiply all prices by4 and separately perturb each one of its five job prices by+1 or-1, retaining positive work/nonnegative other prices. Negative-price constructions are outside the model and are not materialized. The exact resulting input file fixes the denominator before execution. There are no unmodified baseline reruns. Evaluate every budget0..12. All selected source ids, mutations and their provenance remain visible in INPUTS.

Use the original explicit five-state graph/AND-OR shortest-path solver with only the root and macro budget range changed from0..6 to0..12. It checks every reachable Bellman equation and termination of the selected policy. Compare each all-U full-game root with the three-mode value. A strict lower full-game value is a counterexample to the still-unproved general equality. The test does not establish a universal equality if no gap occurs.

Also check the newly derived author bounds, without using them to prune the full game: Hflat<=Vfull<=H and H-Bmu<=Vfull, where pflat=min(p,m) only for jobs with m>0 and p>m, and mu is the largest such m. Check H-Hflat<=sum of clipped premium differences and exact equality for B<=1 or mu=0. Hflat is a separate macro DP with clamped prices; these comparisons are diagnostic consequences of the proof, not the method used to obtain full-game values.

Each input has a5second cap, the campaign240seconds, and the hard stop05:00UTC. Every input receives SUCCESS, FAILURE, TIMEOUT, INVALID, or NOT_RUN. Preserve all logs and first counterexample if any. No exclusion or unchanged rerun; a revision requires a new directory with its reason. This is a finite author counterexample search, not a proof, final evaluation, or native application evidence.
