# Independent finite-policy oracle for retained refresh

Fixed before execution, 2026-09-10. This is an author-side implementation check, not a new performance experiment or an independent blind review.

The oracle will enumerate complete worst-cost vectors over all integer budgets through H=q*max_D c(D), using set-union BFS for attainable masks and their minimum write counts. At a policy node, each observed mask has an independently chosen accept or reject/subpolicy branch. Cartesian combination takes the componentwise maximum of branch cost vectors; identical and componentwise dominated vectors can be removed because every ancestor operation is monotone. It does not use the compiler's threshold recurrence. Direct completion is a separate root vector. The pointwise minima give the informed comparator; minimizing the maximum gap to that comparator gives the unknown-budget loss. Budget H exposes every length-at-most-q observation sequence, so values are constant afterwards.

Inputs: weights (1), (3), (1,2), (2,5), (1,2,3); for one component q=1..5, for two components q=1..3, for three components q=1..2. Footprints: all singleton sets; singleton sets plus the full set; and (for three components) {1,3,6}. Duplicated footprint families are removed by exact tuple identity. Coefficients alpha,beta,rho independently range over {0,1,3}. All are nonnegative integer resource coefficients, not latency fits.

For every condition compare the full informed curve (extending the compiler's reported curve by its final value), the best unknown-budget loss, the best loss when initial preparation is mandatory, and the actual compiled policy's full cost curve/loss. Also check the one-component closed form, without using it in policy enumeration. Save each result including all frontier vectors. No condition may be omitted or retried to hide a failure. A 300-second execution bound will preserve partial rows and report an incomplete denominator on timeout. Any code correction gets a new run directory with the earlier result retained. Exact source/input hashes are recorded before execution.
