# Claims, evidence and reproduction

This map concerns the manuscript and evidence in snapshot `fgducs-c114-20261003` of the anonymous public repository. This authors' replication package includes the cited [Technical Appendix A–P and Supplement S1–S5](../paper/README.md#appendix-section-index). The integrated PDF opens with linked reading routes and complete contents. The main workflow table separates supplied inputs, generated transitions and synthesis outputs. S5 compares native contracts, including prior supervisor switching and workcell reconfiguration; it does not claim that state correspondence first appears here. RQ2 Table 4 distinguishes independent finite-game checks, static NEW and UPD initialization checks, and 25 winning application policies across 125 saved runs; static lookup/source checks do not establish actual activation conformance. Paths are relative to the repository root. Run commands from that root, using fresh output directories when a command writes results.
