# Source and resource interpretation after the bounded studies

The selected Roslyn transformation has evidence beyond endpoint text equality: the guarded rebase preserves the tested notification order and payloads, error-hook behavior, same-text reentry, and selected compiler diagnostics/symbol projections. The rejected earlier patches remain counterexamples to their own implementations. These bounded checks do not prove arbitrary hook or host behavior.

Native rejection necessarily executes instructions. Excluding that execution from a deliberately chosen protected-transformation resource does not by itself refute that resource model; it limits the claim that can be transferred to CPU time or lock latency. Conversely, the partial-repair cost w(D) with a common mu is not established as a native resource law. A global solution-identity mismatch can arise from unrelated changes while the affected target documents remain clean; rebase still performs an existing source operation. Roslyn's text/tree operations can defer parsing and share compiler state, so dirty membership alone need not determine immediate or eventual work.

The whole-kernel placement results, the partial-repair mathematical extensions, and native timing outcomes therefore have different evidential roles. The compact compiler returns exact decisions for a supplied footprint profile. Additive excess removes dependence on a common baseline; a true per-call toll changes the known-budget curve and the all-budget optimality boundary. Neither extension is a measured native model. The source experiments currently support semantic feasibility in a bounded setting and a negative/mixed performance result, not a causal latency improvement.

The strongest remaining research need is a source-supported cost contract and a nontrivial improvement under that contract, together with a precise distinction from nearest prior guarantees. Generic threshold feasibility, rational isolation, and familiar retry/locking mechanisms are not claimed as new merely because they are packaged here. Further experiments should be selected to resolve that need, without converting the current null results into positive claims or expanding the current session past its stop deadline.
