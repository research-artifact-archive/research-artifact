# Fixed corroboration of charged-cost proof candidates

This is the first numerical check of PROOF_CANDIDATE01.md. The generator fixes every input before the checker executes; its receipt provides exact input counts and hashes. It is not a new empirical population. All algebra uses integers exactly.

A compares three methods for supplied B=1,r=0: a visible-branch immediate-operation Pareto recursion with guarded charges; exhaustive topological no-write plans and all fresh/cached subsets for n<=4; and the proposed threshold/Lawler frontier on every fixed input. Every threshold root, frontier difference and attained witness is retained. On larger n, retain the two independent implementations and replay the selected Lawler policies against every no-write/one-cache-invalidation event path. This covers all DAGs with edges increasing in their supplied labels at n<=4, exhaustive work/guard vectors at n<=3, and explicit larger topology/cost boundaries. It does not enumerate all arbitrary concrete programs; that completeness is a proof obligation.

B compares subset-pair enumeration, a capacity-indexed knapsack DP and literal completing-operation traces on the fixed universal zero-write inputs. Selected traces are universally n-call admissible because they use only completing guards, including under additional writes; their evaluated cost is at B0. Exhaustive no-write mode/ready-job recursion is added for n<=4; larger instances use every subset pair plus DP and one reconstructed witness per nondominated point. The powers-of-two family verifies the exact2^n count only for the fixed n1--12; the asymptotic claim is a separate proof. Uniform comparison costs receive a sorted-profit formula check and a polynomial-size bound.

For every fixed knapsack input, test every listed capacity and target. Compare the original item-subset feasibility with the mapped completion frontier and with capacity DP. This checks the encoding, not NP-completeness itself.

The six fixed controls address omitted guards, an incorrectly guarded post-mismatch suffix, omitted total comparison cost, supplied-versus-universal zero-budget confusion, forced caching of nonprofitable jobs, and misapplication of the heterogeneous-cost output claim to uniform costs. The first five must change or violate the specified resource result; the sixth is an expected scope exclusion. Controls are separate from valid inputs and are not silently dropped.

Persist JSONL input-level outcomes, exact input/proof/checker hashes, algorithm counts, witness path counts, all failures and exceptions, and a result receipt. The supervisor caps total execution at900seconds, terminates only its descendant processes on timeout, and marks unexecuted inputs explicitly by fixed minus processed counts. Do not change a failed threshold or omit a failing input. Implementation or protocol corrections require a new filename/output directory and an explanation retaining the original attempt. No paid service, native timing, human/LLM proxy evaluation, or result-based input regeneration occurs.
