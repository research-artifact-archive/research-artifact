# Publication provenance supplement

This supplement adds preparation/freeze provenance and complete earlier scale histories that were not all present in the frozen version-5 distribution. It changes no original scientific outcome. `../package/` remains byte-identical to its pre-publication snapshot.

`history/` preserves the following authored study directories: final DAG primitive evaluation, final native evaluation, original 87-input scale, 57-input hybrid scale, and its later checker. It also includes four prior input registries needed to inspect preparation overlap checks. Material also present in the frozen package is kept for an intelligible preparation history; duplicate files are not new evidence units.

`PROVENANCE.json` lists every included file with its original relative path, original hash/size, public hash/size, and disposition. `EXACT_COPY` means byte equality. `LITERAL_WORKSTATION_PATH_PROJECTION` means only the original session path and author home were replaced by `${SESSION}` and `${AUTHOR_HOME}`. Such files are derivative distribution records, not original preregistrations; embedded historical hashes still refer to the original files unless expressly described otherwise. Original private author-side raw reports, Python caches, and compiled class files are excluded with their hashes recorded. Authored source and class-hash receipts are available; JDK runtime binaries and third-party articles/source copies are not redistributed.

The historical `generate.py`, `prepare.py`, `freeze.py`, and original run drivers make selection order and recorded provenance inspectable. They assume the old workspace layout and some projected receipt paths; they are not the public execution interface and should not be run in place. The public `package/reproduce*.py` entry points instead use the materialized, hash-bound inputs and write into new external output directories. The table aggregation command includes all supplied earlier scale outcomes without launching those original runs.

For native paths, `history/final_evaluation_dag_native_01/generate.py` contains the seeded vector construction, and `prepare.py` contains the success-before-failure path traversal, policy order, IDs, profiles, and first-path-only controls. The corresponding semantic generation grid is in `history/final_evaluation_dag_01/prepare.py`. The review package supports replay from these fixed inputs; it does not claim to reconstruct the historical clock times, original machine state, or all Java schedules.
