## Implementation contract

Query permitsFresh(currentWeight) is O(1) fixed-width arithmetic/heap accesses. The current job is not completed and its weight is transient in the query, inserted exactly once on successful completion. Record cached match/mismatch or fresh in O(log(|D|+1)); mismatch increments k before the completed-weight insertion. Constructor accepts completed weights,k,ell only. No future weights, DAG, n, B, schedule, body-work diagnostics or actual write counter may enter the filter API. Invalid/nonviable states, nonpositive weights, unsafe fresh, null outcome, and long overflow throw before mathematical state mutation. Resource exhaustion/OOME is outside exception-atomicity. k>|D| is supported for the body-only theorem and is not exported to the charged theorem. This is not a heterogeneous-charge implementation. Wrapper validation happens before side-effecting completion when practical; checked long arithmetic is a representable-domain limitation.
