\begin{abstract}
We synthesize causal retry policies for dependent transformations under a finite interference allowance and declared resource prices. Nonzero validation and callback charges can make a third mode essential: prepare outside protection, then atomically reuse or recompute the result. A potential proves that three serial modes attain the minimum worst cost of an atomic-call interface, including programs retaining several preparations and changing jobs between calls. For identity-based Java callbacks, a matching adversary uses at most $B$ actual external writes. All-budget values have supporting slopes in $\{0\}\cup\{w_i+\min(v_i,k_i),w_i+p_i\}$, at most $4n$ positive marginal runs per state, and $2^n\operatorname{poly}(L)$ construction/checking for binary input length $L$. A mixed-price class admits exact $O(|E|+n\log(n+1))$ construction and checking through a two-fee reduction; a general zero-fee subcase is NP-complete at $B=1$. We check 19,485 compact/fallback inputs and 3,700 native Java executions across two implementations. Compact construction/checking completes 32,768-job inputs with 65,536 root runs in at most 1.604 seconds. Requested-value methods can be cheaper. A Deephaven integration loads profiles and preserves captured directives while live actions change under a caller-owned update bound. A separate 72-cell API calibration fails to establish measured third-mode benefit. The guarantees concern the stated resource contracts; application prevalence and elapsed-time improvement remain unestablished.
\end{abstract}

\section{Introduction}

A program can transform a shared object by computing a tentative result and validating it, or by computing inside an atomic callback. The first choice risks repeated work; the second pays for protection. Dependencies add another decision: which ready transformation to attempt next. A compiler for this problem should account for the available operations, rather than assume that a chosen retry pattern already contains an optimal program.

Call costs change that pattern. Consider two independent transformations with the declared prices in Table~\ref{tab:example}. Kernel work is $w$, protected kernel work is $w+p$, a conditional validation costs $v$, and an atomic callback's combined entry/exit charge is $k$. A validation-only callback can be cheaper than the conditional API: it publishes a prepared result on an identity match and leaves the current value unchanged on a mismatch. Hence the cheapest ordinary attempt costs $c=w+\min(v,k)$.

\caption{A constructed two-job example. With at most one invalidation, the three-mode optimum is 8; the optimum using only fresh protection and cheapest-validation retries is 9. These are declared resource charges.}
\label{tab:example}
\centering
\begin{tabular}{crrrrrr}
\toprule
Job & $w$ & $p$ & $v$ & $k$ & $c=w+\min(v,k)$ & Fresh protected cost\\
\midrule
0&3&2&0&0&3&5\\
1&1&1&3&2&3&4\\
\bottomrule
\end{tabular}
\end{table}

Prepare job 1 outside protection, then use a cached callback. On a match it costs $1+2=3$; protect job 0 for 5, giving total 8. On a mismatch the callback recomputes for $1+2+(1+1)=5$; no interference allowance remains, so job 0 costs 3, again giving 8. The best two-mode policy costs 9 even with the same cheaper validation-only callback and adaptive job/mode choices. Thus a cap of 8 changes feasibility. Merely replacing zero validation costs in a two-mode model does not recover the optimum.



We establish a serial normal form for a stated atomic-call interface with nonnegative API charges. Programs may retain several speculative preparations, discard them and switch jobs between completed calls. Protection does not survive a call. Opaque whole kernels, captured immutable predecessor outputs and persistent completion define the batch objective. The theorem identifies an optimum over all causal programs of this interface, rather than over a prescribed ordering or retry threshold. It does not claim optimality for arbitrary concurrent code or exposed, retained locks.

The normal form leaves a finite budgeted game on unfinished job sets. Its direct dynamic program has a state for every remaining budget. We prove that the entire value curve instead has a supporting-line representation using only two input-derived slopes per job. A compiler emits values and runtime choices for all integer budgets, and a separate checker verifies the Bellman equations on finite affine partitions. Binary-encoded large budgets therefore need no budget-by-budget expansion. A mixed-price class reduces further to sorted two-fee packing, with $O(|E|+n\log(n+1))$ construction/checking and a cursor policy of linear size. Outside this compatible class, an NP-complete zero-fee subcase already has one possible failure and two dependency layers.

The operational connection has two levels. For a Java atomic-callback subclass, exact identity semantics give a matching adversary with at most $B$ successful external writes, including when keys share an internal monitor. For Deephaven hierarchical snapshots, source inspection supplies bounds on selected logical operations and an existing public API supplies caller-owned finite refreshes. The latter is an upper-guarantee application of the compiler, with additional update-phase information that can improve the game's value. We report this boundary explicitly.

Budgeted dynamic programming, reflected recurrences and input-slope envelopes are established techniques~\cite{mannor,bkr,bertsimas2003}. The contribution is their justified specialization to charged atomic calls: the third mode and normal-form potential, actual-write correspondence, finite slope-basis closure, and an exact charged-price reduction that removes both budget and subset enumeration on a stated class. The experiments test these claims and their implementation, without treating sparse comparator gains or authored examples as evidence of deployment frequency.

\section{Charged Atomic Calls}
\label{sec:interface}

Write $\N=\{0,1,\ldots\}$. Jobs $J=\{1,\ldots,n\}$ form a finite DAG with predecessor set $\operatorname{Pred}(i)$. Examples and implementation IDs start at zero. A job is ready when all its predecessors have completed. Completion records the exact successful immutable output and persists for the batch, even if a later external write changes the corresponding live object. The objective is one successful foreground transformation per job. It is not a simultaneous all-object snapshot or transaction.

Each ready job has a pure, opaque, whole kernel. It receives an own-input identity and the exact completed outputs of its predecessors. Its fixed unprotected work is $w_i>0$; under protection it costs $w_i+p_i$, $p_i\ge0$, including predecessor processing. Kernels finish and return their exact result. They cannot be partially evaluated, replaced by incremental computations, prepared before readiness or discharged by external work. A preparation is a capability tied to its input identity and predecessor tuple. Captured outputs cannot be reconstructed by later reads of the mutable map.

A local state is $\U$ (no usable current preparation), $\C$ (a usable current preparation), or $\D$ (completed). Several ready jobs may simultaneously be in $\C$. Initially every job is $\U$. An invalidation changes an own-input identity, preserving captured predecessor outputs. The environment has a global remaining allowance $b$, initially $B\in\N$. At zero allowance only matching outcomes are legal.

The declared charge $v_i\ge0$ covers an identity-conditional publication call. The charge $k_i\ge0$ covers entry and exit of an atomic callback, including a callback that only validates. It may be supplied as $g_i+r_i$. These charges define a resource metric; they are not measurements of API latency. All prices are integers, or rational prices scaled uniformly to integers. Table~\ref{tab:calls} defines the available counted operations. A callback holds protection only during that operation and performs no other job's foreground work.

\label{tab:calls}
\centering
\begin{tabular}{llll}
\toprule
Operation & Start & Matching outcome/cost & Mismatching outcome/cost\\
\midrule
Prepare & $\U$ & $\C$, $w_i$ & ---\\
Conditional publication & $\C$ & $\D$, $v_i$ & $\U$, $v_i$\\
Validation-only callback & $\C$ & $\D$, $k_i$ & $\U$, $k_i$\\
Fresh callback & $\U$ & $\D$, $k_i+w_i+p_i$ & ---\\

\bottomrule
\end{tabular}
\end{table}

Discarding a preparation is free. A free inspection is permitted only with a legal outcome that preserves a currently usable preparation; it cannot certify that future interference is exhausted. Programs can select any ready job after any completed call, retain preparations or repeat inspections. There is no bare acquire/release operation, guard-retaining return or cross-job batch callback. All calls finish, and every noncompleting program, including one executing free cycles forever, has infinite objective. The environment resolves outcomes after observing the program's action.

This distinction between a call boundary and a retained guard is substantive. A program with an exposed guard may preserve protection while choosing its next operation. Positive guard/API costs can then defeat simple serial-macro arguments. The charged theorem below covers the atomic-call interface in Table~\ref{tab:calls}. The richer zero-fee interface and known counterexamples outside this boundary are retained in Section~\ref{sec:limits}.

\section{A Three-Mode Normal Form}
\label{sec:normal}

Write $S$ for the unfinished jobs and
\[
\mathcal A(S)=\{i\in S:\operatorname{Pred}(i)\cap S=\varnothing\}
\]
for available jobs. Reachable unfinished sets are upsets. For proofs we extend the game to all subsets, treating absent predecessors as completed. Define
\begin{equation}
\begin{aligned}
m_i&=\min(v_i,k_i),& c_i&=w_i+m_i,\\
\delta_i&=k_i-m_i,& P_i&=p_i+\delta_i,\\
s_i&=w_i+p_i.
\end{aligned}
\label{eq:prices}
\end{equation}
An unavoidable baseline from an all-unprepared start is $A(S)=\sum_{i\in S}c_i$. Three serial modes remain at boundaries where unfinished jobs have no retained preparation:

\begin{enumerate}
\item \emph{Protected}: execute a fresh callback, paying $c_i+P_i$, and remove $i$.
\item \emph{Cheap validation}: prepare and invoke the cheaper validation API. A match pays $c_i$ and removes $i$; a mismatch pays $c_i$, leaves $i$ unprepared and spends one token.
\item \emph{Cached completion}: prepare and invoke a cached callback. A match pays $c_i+\delta_i$; a mismatch pays $c_i+\delta_i+s_i$ and spends one token. Both remove $i$.
\end{enumerate}

Subtract the once-paid baseline. The optimal worst excess of these modes satisfies $F(\varnothing,b)=F(S,0)=0$ and, for $b>0$,
\begin{equation}
F(S,b)=\min_{i\in\mathcal A(S)}\left\{
\begin{aligned}
&P_i+F(S-i,b),\\
&\max\{F(S-i,b),\ c_i+F(S,b-1)\},\\
&\delta_i+\max\{F(S-i,b),\ s_i+F(S-i,b-1)\}
\end{aligned}\right\},
\label{eq:bellman}
\end{equation}
where $S-i=S\setminus\{i\}$. At $b=0$ cheap validation attains zero excess; the cached option has excess $\delta_i$, without a mismatch branch. Each mode outcome decreases $|S|+b$, so a minimizing deterministic controller finishes within $n+B$ mode invocations. This is worst-path control against an adaptive environment, not expected-cost control against a fixed distribution.

\begin{theorem}[Charged atomic-call normal form]
\label{thm:normal}
For the interface of Section~\ref{sec:interface}, the minimum worst cost over all causal programs from the all-unprepared state is
\[
\operatorname{OPT}(J,B)=\sum_{i\in J}c_i+F(J,B).
\]
A serial three-mode controller attains it. Programs retaining several preparations or changing jobs between calls cannot improve the value.
\end{theorem}
\begin{proof}
The three modes implement Table~\ref{tab:calls} with exactly Equation~\eqref{eq:bellman}'s full costs. Their decreasing rank and captured successful outputs give the upper bound.

For the lower bound, let $x$ be any interface state with unfinished set $T$. Define
\begin{equation}
\Phi(x,b)=\sum_{i:x_i=\U}c_i+\sum_{i:x_i=\C}m_i+F(T,b).
\label{eq:potential}
\end{equation}
Every cached job was physically ready when prepared, and its predecessors remain completed. It is therefore available in $T$. We show that every call has a legal outcome with immediate cost plus successor potential at least $\Phi(x,b)$. Terms belonging to unchanged jobs cancel.

Preparation pays $w_i=c_i-m_i$ and replaces the $c_i$ term by $m_i$, preserving the sum. A validation call has charge $z_i\in\{v_i,k_i\}$. Relative to its cached baseline $m_i$, success has excess
\[
z_i-m_i+F(T-i,b),
\]
and mismatch has excess $w_i+z_i+F(T,b-1)$. Since $z_i\ge m_i$, their maximum dominates the cheap-validation option in Equation~\eqref{eq:bellman}. At $b=0$ the matching branch suffices.

A fresh callback pays $c_i+P_i$ and removes $i$; its inequality is the protected option. A cached callback, after subtracting its old cached baseline, gives the two excesses
\[
\delta_i+F(T-i,b),\qquad
\delta_i+s_i+F(T-i,b-1).
\]
Their maximum is the cached option. Discarding $\C$ increases the potential by $w_i$; inspection admits a preserving branch.

Nature selects a witnessing branch after each action, within budget $b$. Telescoping gives the initial potential as a cost lower bound, covering arbitrary job switching and retained preparations. Noncompletion costs infinity; intermediate potentials need not equal intermediate optima.
\end{proof}

A resource cap $M$ is feasible exactly when $A(J)+F(J,B)\le M$. Prices and allowance are supplied; restricted or correlated outcomes preserve the upper guarantee but may lower the optimum.

\begin{proposition}[An open common-fee separation]
\label{prop:commonfee}
For two independent jobs with work $0<w\le W$, common $v_i=k_i=\kappa$, and $p_i=\lambda w_i$, the third mode strictly improves the optimum at $B=1$ exactly when
\[
\frac{w}{W}<\lambda<\min\!\left\{\frac{\kappa}{w},\frac{w+\kappa}{W}\right\}.
\]
In this interval the excess improvement is
$\min\{\lambda w,\lambda W-w,w+\kappa-\lambda W,\kappa-\lambda w\}$.
\end{proposition}
\begin{proof}
Write $f_x=\min(\lambda x,x+\kappa)$ for a singleton. The two-mode excess reduces to
$T_2=\min\{\lambda(w+W),\max(f_W,w+\kappa)\}$; the better cached choice is the smaller job, with $Q=\max\{f_W,(1+\lambda)w\}$. If $\lambda W\le w$, $\lambda W\ge w+\kappa$, or $\lambda w\ge\kappa$, then $Q\ge T_2$. Otherwise $f_W=\lambda W$ and $T_2=\min\{\lambda(w+W),w+\kappa\}$. Subtracting $Q$ gives the displayed positive minimum.
\end{proof}
For $(w,W,\kappa)=(1,2,2)$ the interval is $1/2<\lambda<3/2$; at $\lambda=1$ total costs are 9 and 10. Thus the separation survives within a family having one shared protection weight and one shared call price. These are resource-price conditions; Section~\ref{sec:eval} tests, unsuccessfully, a measured mean-time interpretation.

\section{Actual External Writes in Java}
\label{sec:java}

Repeated stale rejection need not require a new write; writes to completed parents preserve captured outputs.

Use Java 17's \texttt{ConcurrentHashMap} with one foreground thread, distinct persistent keys, immutable identity-equal wrappers and fresh, never-reused identities for external writes. Each job updates only its fixed key. Keys are not removed; results are non-null; kernels use own snapshots and captured parents and terminate without exceptions. Conditional replacement accepts identity or \texttt{equals} equality~\cite{cmap17,chmsource17}; atomic \texttt{compute} invokes its callback once, under a bin monitor in the inspected source~\cite{chm17,chmsource17}. Different keys may share bins.

Implement Table~\ref{tab:calls} using \texttt{replace(key,expected,result)} and \texttt{compute}. Validation-only callbacks return the prepared result on match, otherwise the unchanged entry with a failure flag; cached callbacks recompute on mismatch, and fresh callbacks always compute under protection. Capture permanent milestones locally rather than rereading the map.

Callbacks perform no other-key map operations, other foreground kernels or direct guard work, including on cached matches; no guard survives. Multiple preparations are allowed. Prices charge the specified calls; bin collisions add no unperformed kernel work. Assume scheduling and call completion: finite write counts do not imply fairness.

\begin{theorem}[Matching actual-write environment]
\label{thm:writes}
Under these conditions, with no initial preparations and at most $B$ successful external writes,
\[
\min_P\ \sup_{E:\#\mathrm{writes}(E)\le B}\operatorname{Cost}(P,E)
=\sum_i c_i+F(J,B).
\]
The equality holds for separate or shared internal bins.
\end{theorem}
\begin{proof}
For any admissible program, classify an unfinished job as $\C$ exactly when some retained result has its current identity; otherwise classify it as $\U$. Multiple copies do not create extra capabilities. Set $\beta=B-\#\mathrm{writes\ already\ made}$ and use Equation~\eqref{eq:potential} with $b=\beta$.

The lower-bound environment writes only immediately before a selected comparison or callback acquires its monitor. If a current prepared result is about to be validated, it can choose no write or one fresh-identity write. The two cost/potential inequalities are precisely the validation and cached-callback cases in Theorem~\ref{thm:normal}. Each chosen invalidation costs one actual write and changes only that job's identity. The foreground holds no monitor at this boundary, so the selected write can finish even when keys collide.

Fresh preparation on the current identity pays for the $\U$-to-$\C$ credit change. Computing from an old identity creates no current capability and pays nonnegative cost. Validating an already stale snapshot is a zero-write rejection, leaving the semantic state unchanged; it is not charged another interference token. A cached-completion callback using a stale snapshot recomputes under protection without requiring another write. If the job is $\U$, its excess above the removed baseline is $k_i+s_i-c_i=P_i$; if another current preparation exists and the job is $\C$, it is $k_i+s_i-m_i=w_i+P_i$. Both use the protected inequality. A stale validation-only callback instead preserves the current live entry and pays a nonnegative charge. Fresh callbacks also use the protected inequality. Discarding the only current preparation increases the potential; copying, retaining stale preparations and free preserving inspections cannot decrease it. Captured parents remain valid when their live entries change.

Thus every observed operation admits a zero/one-write continuation preserving cost plus potential. At most $B$ writes are inserted, and telescoping gives the lower bound. Shared-bin protection ends at each call boundary; the no-other-job-work rule prevents it from doing additional foreground work for free.

For the upper bound, the emitted serial controller rereads after every failed cheap validation. Its read-to-validation intervals are disjoint. Every failure requires an external write in its interval, so failures inject into distinct writes. A mismatching cached completion likewise consumes an interval containing a write and then removes its job. There are at most $B$ such outcomes. The controller's remaining allowance may exceed the actual remaining-write count, which is conservative. The three modes therefore meet the compiled upper bound in either layout.
\end{proof}

\paragraph{Operational accounting.}
The native test kernels fold captured predecessor seeds and every entry in an immutable array using fixed arithmetic. For integer $w_i$, choose length $8w_i-|\operatorname{Pred}(i)|>0$ on the selected inputs. Parent and array folds count $8w_i$ units. Protected kernel execution adds $8p_i$, identity-conditional calls add $8v_i$, and atomic calls add $8k_i$, including mismatches. This scales the abstract objective uniformly by eight. Allocation, monitor waiting, map/API instructions outside these declared charges, initialization and background work are excluded. The experiment does not estimate those costs from timings.

\section{All-Budget Compilation}
\label{sec:curves}

Direct evaluation requires up to $(B+1)N$ states, $N\le2^n$. Our binary-input construction removes budget enumeration; arbitrary DAGs still retain the ideal dimension.

\subsection{Reducing the Self-Referential Choice}

\begin{lemma}[Subset monotonicity and cheapest validation]
\label{lem:priority}
If $T\subseteq S$, then $F(T,b)\le F(S,b)$. For any minimum-$c_i$ job $i\in\mathcal A(S)$, its cheap-validation option is no larger than that of any other available job.
\end{lemma}
\begin{proof}
For monotonicity, simulate a policy for $S$, completing omitted jobs without invalidation and with nonnegative excess. Relay retained jobs' actions and outcomes. Every virtually available retained job is physically available; omitted jobs spend no token. Physical cost never exceeds virtual cost. Equivalently, induction on $|S|$ and $b$ compares corresponding terms of Equation~\eqref{eq:bellman}.

At $b=0$ all cheap-validation values are zero. For $b>0$, let $j\ne i$ be available. It remains available after removing $i$. Choosing cheap validation of $j$ in $S-i$ and using monotonicity gives
\[
F(S-i,b)\le\max\{F(S-\{i,j\},b),c_j+F(S-i,b-1)\}
\le\max\{F(S-j,b),c_j+F(S,b-1)\}.
\]
The other branch $c_i+F(S,b-1)$ is also bounded by the last maximum. Their maximum is the cheap-validation value for $i$.
\end{proof}

For a child curve $f$ with $f(0)=0$, define the insertion operator
\[
(I_s f)(0)=0,\qquad (I_s f)(b)=\max\{f(b),s+f(b-1)\},\quad b\ge1.
\]
Fix a cheapest available $i$, put $g(b)=F(S-i,b)$, $c=c_i$, and
\begin{equation}
h(b)=\min_{j\in\mathcal A(S)}\{P_j+F(S-j,b),\ \delta_j+I_{s_j}F(S-j,\cdot)(b)\}.
\label{eq:h}
\end{equation}
At zero, $h(0)=\min_j\{P_j,\delta_j\}$ is allowed to be positive. Monotonicity and feasible completing modes give $g(b)\le F(S,b)\le h(b)$. Equation~\eqref{eq:bellman} becomes
\begin{equation}
f_0=0,\qquad f_b=\min\{h(b),\max[g(b),c+f_{b-1}]\},\quad b>0.
\label{eq:caprec}
\end{equation}
This is a specialization of a reflected recurrence~\cite{bkr}, not a new general dynamic-programming principle. Its particular child curves permit the following closed form.

\begin{lemma}[Concave floor and cap]
\label{lem:cap}
Suppose $g,h$ are nonnegative, nondecreasing and discrete concave, $g(0)=0$, and $h\ge g$. Define
\[
D(0)=0,\qquad D(b)=\sum_{t=1}^b\max\{c,\Delta g(t)\},\quad c>0.
\]
Then Equation~\eqref{eq:caprec} has solution $f_b=\min\{h(b),D(b)\}$, which is nondecreasing and discrete concave.
\end{lemma}
\begin{proof}
Since $\Delta g(t)-c$ is nonincreasing,
\[
D(b)=\max_{0\le t\le b}\{g(t)+c(b-t)\}=\max\{g(b),c+D(b-1)\}.
\]
Induct on $b$. If $h(b-1)\ge D(b-1)$, substitute this identity directly. Otherwise choose a maximizer $t$ for $D(b-1)$. Because $h(b-1)\ge g(b-1)$, the strict inequality requires $t<b-1$. From $h(t)\ge g(t)$,
\[
h(b-1)-h(t)<c(b-1-t).
\]
Concavity makes the next difference of $h$ smaller than $c$. Thus the recurrence selects $h(b)<c+h(b-1)$. The same block inequality for $g$ makes $D(b)=D(b-1)+c>h(b)$. This proves the formula in both cases, including the origin. Flooring preserves nonincreasing nonnegative differences. Pointwise minima preserve nondecreasingness and discrete concavity: minimize $2u_b\ge u_{b-1}+u_{b+1}\ge\min_u u_{b-1}+\min_u u_{b+1}$ over the candidate curves.
\end{proof}

\subsection{Integer Insertion and Supporting Slopes}

We prove the cached maximum's concavity through its marginal structure.

\begin{lemma}[Integer marginal insertion]
\label{lem:insertion}
Let a bounded curve with $f(0)=0$ have a nonnegative supporting representation $f(b)=\min_{d\in D}(db+q_d)$ for all integer $b\ge0$, with finite $D\subseteq\mathbb R_{\ge0}$ and $0\in D$. For $s>0$, define
\[
Q_s=\max_{b\in\N}\{f(b)-sb\}.
\]
Then
\begin{equation}
I_s f(b)=\min\left\{sb+Q_s,\ \min_{d\in D}\bigl(db+q_d+(s-d)_+\bigr)\right\}.
\label{eq:insertion}
\end{equation}
Its marginal sequence is that of $f$ with one additional marginal $s$ inserted in decreasing order.
\end{lemma}
\begin{proof}
The marginals of $f$ are nonincreasing and eventually zero. Let $t$ be the number at least $s$. For $b\le t$, $I_s f(b)=f(b)$; for $b>t$, it equals $s+f(b-1)$. This proves insertion and gives $Q_s=f(t)-st$.

Every line on the right of Equation~\eqref{eq:insertion} majorizes this inserted curve. Before $t$, unchanged slopes at least $s$ already majorize $f$; smaller slopes receive a nonnegative shift. After $t$, shifting a smaller slope by $s-d$ exactly forms $s$ plus its old value at $b-1$, while a larger slope provides at least the same increase. The contact line $sb+Q_s$ majorizes both portions.

For attainment, an active supporting slope $d_b$ at integer $b$ satisfies
\[
\Delta f(b+1)\le d_b\le\Delta f(b),
\]
where only the first inequality is needed at $b=0$. At $b<t$ an active line therefore has slope at least $s$ and is unchanged. At $b=t,t+1$ the contact line attains. At $b\ge t+2$, an active line at $b-1$ has slope smaller than $s$ and its shifted version attains. The cases $t=0$ and $f\equiv0$ follow from the same contact line.
\end{proof}

The contact is over integers. For $f(b)=\min\{100,b+1,3b\}$ and $s=2$, $I_s f(1)=2$. Replacing the integer contact 0 by the continuous supporting envelope's supremum $1/2$ gives $2.5$ in Equation~\eqref{eq:insertion}. Computing a real contact and rounding afterwards is not the stated identity.

The floor operation also preserves a finite input-slope basis. If $f(b)=\min_d(db+q_d)$ and $c>0$, then
\begin{equation}
\sum_{t=1}^b\max\{c,\Delta f(t)\}
=\min\left\{cb+Q_c,\ \min_{d>c}(db+q_d)\right\}.
\label{eq:floorbasis}
\end{equation}
Let $a=\#\{t\ge1:\Delta f(t)>c\}$, the first integer maximizing $f(b)-cb$. The floor equals $f$ through $a$, and equals $cb+Q_c$ thereafter. At $b<a$ every attaining line has slope above $c$; at and after $a$, each retained larger-slope line stays above the contact line. This definition also handles a plateau with marginal exactly $c$, or $a=0$, without special rounding.

\begin{theorem}[All-budget basis and encoded size]
\label{thm:curves}
For every residual set $S$, $F(S,\cdot)$ is nonnegative, nondecreasing and discrete concave, with eventual value $\sum_{i\in S}P_i$. It has a supporting representation
\begin{equation}
F(S,b)=\min_{d\in\mathcal D_S}(db+q_{S,d}),\qquad
\mathcal D_S\subseteq\{0\}\cup\{c_i,s_i:i\in S\}.
\label{eq:basis}
\end{equation}
There are at most $2|S|+1$ lines and at most $4|S|$ positive marginal runs. All reachable-state curves and action data can be constructed and checked in $2^n\operatorname{poly}(L)$ bit time, with no iteration through the magnitude of $B$.
\end{theorem}
\begin{proof}
Induct on $|S|$, starting with the zero line for the empty set. By Lemma~\ref{lem:insertion}, each cached term in $h$ shifts existing intercepts and adds only slope $s_j$. Protected terms shift intercepts by $P_j$. Their minimum is a concave supporting envelope. Lemma~\ref{lem:priority} gives $g\le F\le h$ independently of the desired formula, so Lemma~\ref{lem:cap} applies. Equation~\eqref{eq:floorbasis} adds only the cheapest available $c_i$. Union the line families and retain the smallest intercept per slope. This proves Equation~\eqref{eq:basis}, concavity and nondecreasingness.

Protecting all jobs gives the bound $\sum_iP_i$. A bounded finite lower envelope of nonnegative slopes is eventually constant; let its limit be $L_S$. By smaller-set induction, sufficiently large budgets in Equation~\eqref{eq:bellman} satisfy
\[
L_S=\min_{i\in\mathcal A(S)}\left\{
P_i+\sum_{j\in S-i}P_j,\quad c_i+L_S,\quad
\delta_i+s_i+\sum_{j\in S-i}P_j\right\}.
\]
Here $c_i>0$ and $\delta_i+s_i=P_i+w_i>P_i$, forcing $L_S=\sum_{i\in S}P_i$.

At most $2|S|$ distinct positive slopes give at most that many continuous-envelope changes. Integer sampling adds at most one bridging unit interval per noninteger change, so at most $4|S|$ positive runs suffice. This is a conservative upper bound, not a tightness claim. Summing $4|S|+1$ over all subsets gives $(2n+1)2^n$ profile entries, with at most $n2^n$ action identities.

Generated intercepts obey $0\le q_{S,d}\le\sum_{i\in S}(P_i+w_i)$. A protected shift adds $P_i$; a cached shift adds at most $\delta_i+s_i=P_i+w_i$; a new contact is bounded by child saturation; flooring retains old intercepts. Contacts require no unbounded search: for profile triples $(a,y,d)$,
\[
Q_s=\max_{(a,y,d)\in\operatorname{profile}(f)}(y-sa).
\]
Each piece is affine and the final constant tail decreases after subtracting $sb$, so a listed breakpoint attains the maximum. Intercepts, integer slopes and crossing-neighbor positions consequently have polynomial bit length in $L$. Each state uses polynomially many shifts, contacts and envelope intersections on $O(n)$ lines. Affine-partition checking below has polynomially many such endpoints per state. Enumerating at most $2^n$ states proves the bit bound.
\end{proof}

\subsection{Emitted Policies and Independent Checking}

Profiles store $(a,y,d)$ for $y+d(b-a)$ between integer starts, with decreasing positive marginal runs and a constant tail. Both constructors process reachable upsets child-first: one uses floor/cap composition, the other Equations~\eqref{eq:insertion}--\eqref{eq:floorbasis}. Neither enumerates budgets.

Runtime selection evaluates Equation~\eqref{eq:bellman} using $O(n)$ indexed profiles and a deterministic argmin, with polynomial query cost in $n$, stored size and $\log(B+1)$. It decrements the allowance on mismatch. At zero budget choose a zero-excess mode: cheap validation qualifies, and cached completion ties when $\delta_i=0$. Optimal ties need not give pointwise dominance.

The checker imports no constructor. It reconstructs readiness and the reachable domain, validates raw and derived prices, baseline, available-job lists, cheapest-fast IDs, origins, continuity, decreasing slopes and tails, and verifies Bellman equality. Partition at own/child starts and their one-step shifts. Within each interval all atomic expressions are affine. Checking endpoints and floor/ceiling neighbors of all crossings proves equality throughout; check the constant final interval directly. Compare the supporting basis with its emitted curve by the same affine method.

Induction on $|S|+b$ certifies values and the mathematical argmin. Executable selection, arithmetic, parsing and the operational abstraction remain trusted or separately tested. Earlier routing-binding failures remain recorded in the artifact and repaired by RQ1's field checks. Polynomial-per-state bounds concern generated certificates; arbitrary encodings additionally cost their supplied length. Checking does not establish application-price adequacy.

\paragraph{What a requested-value query can skip.}
Large $b$ need not require a profile. Classical concave allocation~\cite{federgruen} gives the following charged-model bounds:
\begin{equation}
\max_{\substack{b_i\in\N\\\sum_i b_i\le b}}\sum_{i\in S}\min(P_i,b_ic_i)
\ \le F(S,b)\le\
\min_{t\in\{0\}\cup\{c_i:i\in S\}}\left(\sum_{c_i>t}P_i+bt\right).
\label{eq:elementarybounds}
\end{equation}
For the lower bound, assign private failure budgets $b_i$. Protected or cached-failure completion pays at least $P_i$; any other completion after exhausting its private allowance has already paid $b_ic_i$ in cheap failures. Their total allowance is at most $b$. For the upper bound, protect jobs with $c_i>t$ and retry the others in any topological order. Their failure costs are at most $t$. The allocation merges compressed marginal runs: $\lfloor P_i/c_i\rfloor$ copies of $c_i$, then $P_i\bmod c_i$ if nonzero. It never iterates to $b$. Equality certifies a value directly, and $b\ge\sum_i\lceil P_i/c_i\rceil$ guarantees the constant tail $\sum_iP_i$. Our requested-value comparator uses these tests at every subproblem and separately certifies equality leaves and concave peaks. It returns requested values, whereas the full artifact additionally supplies all-budget profiles and routing data.

\section{A Compact Charged Class and the General Barrier}
\label{sec:complexity}

The general compiler handles arbitrary dependencies and prices. A price condition, however, permits a stronger result even with positive call charges and an essential cached mode.

\subsection{Reducing Mixed Charges to Two Fees}

For a concave suffix $f$ with $f(0)=0$, write
\begin{equation}
R_{a,q}f(b)=f(b)+\min\left\{q,\sum_{\ell=1}^b(a-\Delta f(\ell))_+\right\}.
\label{eq:reduceddeficit}
\end{equation}
This is the two-fee operator with failure price $a>0$ and protected premium $q\ge0$: by Lemma~\ref{lem:cap}, it equals $\min(f+q,L_a f)$, where $L_a f(b)=\max_{0\le j\le b}\{f(j)+a(b-j)\}$. It is monotone in $f$.

\begin{lemma}[Two-fee ordering and packing]
\label{lem:twofee}
Independent two-fee jobs admit a fixed optimal nondecreasing-$a$ completion order, including against adaptive choices. Composing their $R$ operators in this order gives their value $H$. Reverse composition fills marginal deficits below the next $a$: all positive suffix marginals except possibly the last are at least $a$. Each job adds at most two runs. Every sorted suffix is the root curve capped at its remaining premium sum.
\end{lemma}
\begin{proof}
Let $G$ be the optimum restricted to the sorted order. Inserting a protected job $i$ at its sorted position gives $G(S,b)\le q_i+G(S-i,b)$ without spending a token. Induct on $|S|+b$. The first sorted job has minimum failure price; the proof of Lemma~\ref{lem:priority}, with only protected and cheap modes, makes its cheap option no larger than any other's. The smaller-set and previous-budget values equal $G$ by induction. Thus $G$ is bounded above by every unrestricted Bellman option, while feasibility gives the reverse inequality.

Equation~\eqref{eq:reduceddeficit} preserves marginals at least $a$ and raises smaller ones toward $a$ using at most $q$ mass. In reverse sorted order, only the final positive singleton can be below $a$. Raise it first; write any remaining mass as $ha+r$, $0\le r<a$, and append $h$ copies of $a$ and one $r$ if nonzero. Constantly many run operations suffice. Removing the added tail mass recovers the previous suffix, proving the cap identity.
\end{proof}

\begin{theorem}[Exact mixed-price reduction]
\label{thm:chargedorder}
Suppose $p_i\delta_i=0$ for every job, with the original prices from Equation~\eqref{eq:prices}, and set
\begin{equation}
t_i=\begin{cases}\min(c_i,s_i),&\delta_i=0,\\c_i,&\delta_i>0\quad(\text{hence }p_i=0).\end{cases}
\label{eq:effectiveprice}
\end{equation}
For independent jobs, the charged excess $F(S,b)$ equals the two-fee optimum $H(S,b)$ with prices $(t_i,P_i)$ at every integer budget. A fixed nondecreasing-$t$ completion order is optimal. The same equality holds for a DAG satisfying $t_u\le t_v$ on every edge $u\to v$, with ties ordered topologically. The total charge remains $\sum_{i\in S}c_i+H(S,b)$.
\end{theorem}
\begin{proof}
Marginal insertion (Lemma~\ref{lem:insertion}) commutes with deficit filling when $s\ge a$:
\begin{equation}
R_{a,q}I_s f=I_sR_{a,q}f.
\label{eq:commute}
\end{equation}
Indeed, insertion of $s$ precedes every marginal below $a$ and adds no deficit; $R_{a,q}$ changes only those later marginals, raising them at most to $a$.

If $f$ is a sorted suffix with effective costs at least $t$, $s\ge t$ and $q<s$, then $R_{t,q}f\le I_s f$. Before the final partial marginal the deficit is zero. At that marginal the increment is at most $t-\Delta f(b)\le s-\Delta f(b)$; after saturation it is at most $q<s$. These cases also show $R_{s,q}f=\min(f+q,I_s f)$ when $t=s$.

For $\delta_i>0$, $p_i=0$, so cached completion is dominated: $\delta_i+I_{s_i}f\ge P_i+f$. The ordered charged operator is exactly $R_{c_i,P_i}$. For $\delta_i=0$, $P_i=p_i<s_i$, and it is $\min(f+P_i,L_{c_i}f,I_{s_i}f)$. The preceding suffix inequalities make this $R_{t_i,P_i}$, both when $t_i=c_i$ and when $t_i=s_i$. Thus the sorted charged policy attains $H$.

For a matching lower bound, the two-fee Bellman equation bounds $H(S,b)$ by $P_i+H(S-i,b)$ and by $\max\{H(S-i,b),c_i+H(S,b-1)\}$, since $t_i\le c_i$. These cover protected and cheap choices. Positive-$\delta_i$ cached choices are covered by protection dominance. For a zero-$\delta_i$ job at any sorted position, write $H(S)=A R_{t_i,P_i}f$ and $H(S-i)=Af$. Every operator in the preceding composition $A$ has cost at most $t_i\le s_i$. Monotonicity, the suffix inequality and Equation~\eqref{eq:commute} give
\[
H(S)\le A I_{s_i}f=I_{s_i}Af=I_{s_i}H(S-i).
\]
Hence every original charged Bellman option is at least $H$; induction on $|S|+b$ proves the lower bound against adaptive choices. Finally, removing DAG edges gives an independent lower bound, and a compatible sorted topological policy attains it legally.
\end{proof}

The class mixes $k_i\le v_i$ jobs with zero-premium jobs. For Proposition~\ref{prop:commonfee}, $t_i=\min(w_i+\kappa,(1+\lambda)w_i)$ increases with $w_i$, so work order suffices. Effective prices preserve cached choices; the total-cost baseline remains $\sum c_i$.

\subsection{A Checked Cursor Policy}

Minimum-$t$ Kahn traversal finds a sorted topological order when the edge condition holds. Apply Lemma~\ref{lem:twofee}'s packing to $(t_i,P_i)$, retaining the original charged input. For sorted suffix $S_k$, root curve $H$ and $Z_k=\sum_{i\in S_k}P_i$, store
\begin{equation}
F(S_k,b)=\min\{H(b),Z_k\}.
\label{eq:chargedcap}
\end{equation}
The artifact uses $O(n)$ entries beyond the graph. It covers the $n+1$ suffix states reached by its own policy, whereas the general artifact covers every reachable unfinished set.

The separate checker recomputes the reduction, original baseline and order. It validates the root's zero origin, positive integer run lengths, decreasing positive marginal heights, implicit zero tail and total mass $H(\infty)=Z_0$, then checks the two-fee Bellman equations without importing the constructor. For adjacent caps $z=Z_k$, $a=Z_{k+1}$, let $u$ and $v$ be the first budgets where $H$ reaches $a$ and $z$. Check the uncapped prefix, the boundary $u$, the constant marginal $t_i$ between $u$ and $v$, and saturation at $v$; concavity extends marginal endpoint checks across each interval. Zero premiums require identical adjacent caps. The terminal cap is zero. These conditions verify all budgets by suffix induction; Theorem~\ref{thm:chargedorder} supplies the charged/global-optimality reduction. Additional original-mode boundary checks are consistency controls, not a substitute for that proof.

Construction takes $O(|E|+n\log(n+1))$ arithmetic operations. Checking a supplied root with $r$ runs takes $O(|E|+n\log(r+2)+r)$, plus its encoding length. Generated roots have $r\le2n$, giving the same asymptotic bound. Binary operand lengths still count. Prefix lengths/areas give $O(\log(n+1))$ value queries. At a cursor, evaluate the three original branches in Equation~\eqref{eq:bellman} for its fixed next job using adjacent caps. Cheap failure retains the cursor; cached failure spends one token and advances it. All paid charges remain original. Inputs failing the price or edge condition use the general charged compiler.

These are sufficient conditions. With independent $w=(1,1,1,2)$, $p_i=w_i$, common $v=5,k=6$, and $B=1$, ascending work order costs 31, while order $(2,1,1,1)$ and the adaptive optimum cost 30; here $p_i\delta_i>0$. Even with $\delta_i=0$, sorting by $c_i$ can fail: $(w,p,k,v)=(5,6,5,8),(5,4,6,8)$ gives $c=(10,11)$ but $t=(10,9)$, and $B=1$ totals 31 versus 30. Both refutations remain in the artifact.

\subsection{Hardness Outside the Compatible Class}

Set $v_i=k_i=0$. Then $c_i=w_i$, $\delta_i=0$, $P_i=p_i$, and the cached mode is dominated by a cheap attempt followed by immediate protection on failure. Equation~\eqref{eq:bellman} reduces to
\[
V(S,b)=\min_i\{p_i+V(S-i,b),\ \max[V(S-i,b),c_i+V(S,b-1)]\}.
\]
At $B=1$, a topological order $\pi$ and the protected jobs $H$ on its no-failure path have worst excess
\begin{equation}
C(\pi,H)=\max\left\{\sum_{j\in H}p_j,\quad
\max_{i\notin H}\left(c_i+\sum_{j\in H:j\prec_\pi i}p_j\right)\right\}.
\label{eq:onefailure}
\end{equation}
After the one possible failure, every remaining job finishes without excess. Minimizing this expression is exact, so an initially fixed order suffices at one failure.

\begin{theorem}[Single-failure hardness]
\label{thm:hardness}
The zero-fee subcase of deciding $F(J,1)\le K$ is NP-complete with at most two DAG layers, maximum indegree two, unit premiums and at most two distinct positive failure prices.
\end{theorem}
\begin{proof}
An order and its mode bits can be checked in polynomial time by Equation~\eqref{eq:onefailure}. We reduce from CLIQUE~\cite{karp}. After trivial cases, let $k\ge2$, $m\ge\ell=\binom{k}{2}$; add an isolated vertex so the graph has $n>k$ vertices. Set $K=n+m-\ell>k$. Every vertex becomes a job with $(c,p)=(K+1,1)$; every edge becomes a job with $(c,p)=(K-k,1)$ depending on its two endpoints.

A $k$-clique permits protecting its $k$ vertices, running its $\ell$ edges fast, and protecting the remainder if no failure occurs. Failure costs $k+K-k=K$, and no-failure premium is $n+m-\ell=K$.

Conversely, value at most $K$ forces all vertices on the no-failure path to be protected, since one vertex failure costs $K+1$. Every fast edge follows at most $k$ protected jobs. Its endpoints belong to the same first $k$ protected vertices; intervening protected edges cannot enlarge that set. If $f$ edges run fast, no-failure premium $n+m-f\le K$ requires $f\ge\ell$. At most $k$ vertices contain at most $\ell$ distinct edges, so they contain a $k$-clique. Numbers are bounded by $n+m+1$.
\end{proof}

This restricted NP-completeness result does not establish membership in NP for arbitrary binary $B$, nor necessity of ideal enumeration. A cover by $w$ chains of lengths $n_\ell$ bounds the ideal count by $\prod_\ell(n_\ell+1)$: polynomial for fixed $w$ (XP, not an FPT claim).

Even in the zero-fee subcase, dependencies can require adaptive ordering. Jobs with $c=(3,7,5,1)$, $p=(2,2,6,2)$ and edges $0\to1,0\to2,1\to3$ cost 24 versus 26 at $B=2$. After fast job 0 succeeds, the optimum protects job 1 with two tokens left but starts job 2 fast with one token left. Every fixed order receives optimal adaptive modes and knows the initial budget. This is a constructed separation, not a typical-case benefit.

\section{A Source-Derived Hierarchical Snapshot Case}
\label{sec:deephaven}

Deephaven retries optimistic hierarchical snapshots and can fall back to shared-lock execution. The inspected server API extracts key directives ($K$), then materializes an ordered viewport and expanded size ($V$). Its ordinary Web client uploads static keys, so $K$ does not retry. Our two-refreshing-stage configuration is an authored use of the supported server API~\cite{deephavenSource}.

\paragraph{A source-derived resource bound.}
At commit \texttt{6367313a}~\cite{deephavenSource}, fix a 31-row balanced hierarchy, immutable ID/Parent columns, directive keys 0, 1 and 2, a 16-row single-range viewport and four output columns. Operation-entry counters give $W_K=4$, $W_V=104$: the latter contains at most four directive links, four parent lookups, zero unlinks, 32 node operations and 64 output-cell operations. Earlier studies send same-valued Actions; a later fixed study alternates node 1 between \texttt{Contract} and \texttt{ExpandAll}, keeps the other two expanded and changes payloads.

These bounds include mid-body updates. Fixed keys avoid insertion/rehashing. Each partition is one compact range whose iterator retains its bounds when previous-value references advance. Actions select the full tree or its contracted subtree; payloads do not change traversal lengths. Directives add no ancestor or remove a linked child. Expansion uses 32 node operations including null leaves; contraction uses 17 and totals 89 selected operations. Inconsistency exits without traversal restart. These source conditions, fixed before outcomes, justify the common cap 104.

Unprotected selected operations have unit weight, protected ones weight $1+\lambda$. Supply zero call charges and $p_i=\lambda W_i$ to the compiler. Shorter/aborted bodies charge their executed prefix. Allocation, setup, waiting, API instructions and unselected operations are excluded: this is neither whole-program work nor CPU time. Bounds come from source paths and fixed shapes, not trace maxima.

The official real-time-tree example uses periodic updates without a finite total bound~\cite{deephavenTree}. We instead use public \texttt{EventDrivenUpdateGraph} with at most $q$ caller-owned \texttt{requestRefresh} invocations~\cite{deephavenContext,deephavenSource}. Each starts a native cycle, runs sources and notifications, and completes. The foreground has no free operation waiting for all future invocations to disappear.

\paragraph{The evaluated update contract.}
A source latch exposes the interval from START to mutation. Releasing it finishes that refresh through notifications and COMPLETE. Decisions observe synchronized transitions: serial inconsistent bodies charge distinct START or completion boundaries, giving at most $2q$ failures. Shared-lock execution drains an open cycle first. Partially notified interleavings are excluded; native notification state is richer than raw clock parity.

An imported profile for $K\to V$, $B=2q$, bounds bodies by the zero-fee value plus $W_K+W_V$. Inconsistency charges its failed-body cap and consumes allowance; success charges actual selected work. The materialized $K$ directives persist for $V$ even if live Action changes. This gives an upper guarantee; the native graph cannot realize every abstract adversarial choice.

At $\lambda=3,q=2$, the cap is 424. One fast-tie script attains 424 via four full failures over two split cycles. A local rule with the same allowance costs 432: it protects when local failure exposure reaches the premium. Attainability by that policy is not whole-system minimax optimality. A phase-aware mode game drains an open cycle by protection and has value 420, exposing slack in the $2q$ abstraction.

\paragraph{Integration boundary.}
Policy hooks and counters reject skipped/foreign calls, unexpected exceptions or violated bounds; all normal returns are checked. This is a source-instrumented version. The comparison replica implements the upstream two-attempt rule under the same strict harness, with elapsed-time fallback disabled. The graph uses public refreshes, not test-only cycle controls. The caller must own every refresh and supply $q$; thread count, periodic rate or hidden writers do not supply it. Automatic applicability and fee calibration remain separate problems.

\section{Related Work}
\label{sec:related}

\paragraph{Quantitative synchronization synthesis.}
\v{C}ern\'y et al.~\cite{cerny} already choose optimistic retries, guards and caches. Their Theorem~6 preserves limit-average values through matched distributions/weights; an erratum supersedes the original hardness claim. Our potential establishes initial worst-total-cost equality for charged calls and actual writes. Their later work~\cite{cernyquality}, Sections 6.1--6.2, optimizes protected-statement counts and profiles block costs under contention and lock acquisition. Our declared resources lack that performance calibration. Weighted reachability already expresses optimal worst fault cost~\cite{dumitrescu}; resilience/cost synthesis and general game solvers are established~\cite{neider,weinert}.

\paragraph{Reduction and robust dynamic programming.}
Gangamreddypalli et al.~\cite{structured} preserve failures and reach each original successful final state or replace it by failure. Our calls do not commute unconditionally with same-key writes; the potential is not an exact intermediate-state quotient. A cost-preserving reduction remains unestablished. Mannor et al.~\cite{mannor}, Section 4/Theorem 5, provide finite global-deviation-budget DP: unfinished upsets, completing nominal branches and token-consuming failures instantiate it with negated cost and horizon $n+B$. Postek et al.~\cite{postek} supply exact finite-candidate DP, state expansion and causal budgeted routing. These express the finite game; the normal form and all-budget closure need additional arguments.

The public zero-fee package~\cite{artifact} is an earlier snapshot of this same research project. Its hardness, concave floor/cap lemma and two-fee ordering/packing are reused here. The charged additions are the atomic-call potential, second supporting slope, and mixed-price reduction; the artifact maps the results individually.

\paragraph{Envelopes, reflection and allocation.}
Burdzy et al.~\cite{bkr}, Equations (2.12)--(2.13)/Theorem 2.6, give the general reflected recurrence; our floor/cap lemma specializes it to concavity. Marginal insertion is elementary. Bertsimas and Sim~\cite{bertsimas2003}, Theorem 3/Equations (15)--(19), already give an input-deviation slope envelope $Z(\Gamma)=\min_\ell\{\Gamma d_\ell+F_\ell\}$. Such envelopes alone are not new. Here Equations~\eqref{eq:insertion}--\eqref{eq:basis} close the operations for repeated causal failures, two completing modes and dependent job choices. Reduction to a fixed binary robust set remains unestablished. Concave allocation~\cite{federgruen,bertsimas} supplies lower bounds; decision-dependent information and controllable uncertainty are broader settings~\cite{vayanos,ley}.

\paragraph{Scheduling and hardening.}
At one failure, the zero-fee problem couples processing/tail modes $(p_i,0)$ and $(0,c_i)$. Fixed modes use Lawler's precedence sequencing~\cite{lawler}; our hardness concerns selecting modes. Izosimov et al.~\cite{izosimov} activate DAG schedules under bounded failure histories with signalling/transparency constraints; An and Yang~\cite{an} synthesize stochastic hardening under fixed priorities. We omit those constraints. Chrobak et al.~\cite{chrobak}, Lemma 4/Theorem 5, concentrate faults on a critical job and compute prescribed-order latest completion in $O(n)$ independently of the fault bound. Their model mandates retry; ours chooses priced protection/cached completion and returns all-budget counted-work policies. Bold and Goerigk~\cite{bold} use $\Gamma+1$ DAG layers and a compact MIP after duration observation. Their activities complete despite delay; our failure leaves a job unfinished before another causal choice.

\paragraph{Ordering and rent-or-buy.}
Heterogeneous thresholds and ordering appear in ski rental~\cite{wu,li}. The direct map $f(H)=\sum_{i\in H}p_i$, $g(H)=\sum_{i\in H}c_i$, $T=B$ gives 6 for $(p,c)=(2,5),(4,6)$ at $B=1$, versus our zero-fee value 5. This excludes only that map: shared interference, mandatory work and causal completion must be matched. At $B=1$, charged fixed-order excess is $\psi_{\pi_1}\circ\cdots\circ\psi_{\pi_n}(0)$ with $\psi_i(x)=\min\{x+P_i,\max(x,c_i),\delta_i+\max(x,s_i)\}$. Kawase et al.~\cite{kawase} establish optimal composition, exchange arguments and tractable/hard piecewise-linear scheduling classes. That scalar view is inherited. Their results do not directly resolve our generally nonconvex/nonconcave maps, and one-budget composition does not establish the all-budget reduction or closure.

\section{Limitations and Threats to Validity}
\label{sec:limits}

The charged theorem requires whole fixed-price kernels, own-input identity changes, captured immutable parents, persistent completion, terminating calls and no retained protection or cross-job foreground work inside callbacks. Partial/incremental evaluation, replenished budgets, structural changes, exceptions and external milestone discharge are outside it. A free certificate that all future writers have finished can reduce the optimum to baseline work, so such an operation cannot be added without analysis. The map itself supplies neither the finite write allowance nor calibrated prices.

The richer zero-fee interface admits individual or batch guard acquisition, retained guards and preparations. Its earlier one-pass/potential argument shows equality with the two-mode game from an all-unprepared boundary. Charging exposed guard operations changes that argument. Earlier positive-cost failed-acquisition experiments retain five strict improvements among 384 inputs, including unrestricted 242 versus macro 243. In a later exposed-guard model, a proposed local rule releasing a failed guard or completing it immediately is refuted by an intermediate-state value 43 versus 45. Full all-unprepared equality for that charged exposed-guard model remains unproved, despite finite agreement. We do not use the atomic-call theorem to close those questions.

The Deephaven guarantee covers selected operations, a fixed hierarchy/directive-key set, the stated Action changes, owned finite refreshes and synchronized boundaries. Ordinary Web use has a static key stage; periodic operation has no supplied finite $q$. Source notification state distinguishes executions with the same raw clock. The public-graph study establishes an API composition and resource accounting; deployed frequency and exact whole-system minimax optimality remain unknown. Zero observed prefix aborts and policy-conditioned suppression of writer cuts remain part of the result.

All tests are authored and finite, and proofs are not mechanically verified. Certificate checking establishes the declared game's equations; native traces test implementations under recorded schedules. Strong-comparator gains are sparse in some families, and direct methods avoid timeouts incurred by full construction. The API calibration does not supply a measured positive premium or a timing benefit; threshold relaxation after its outcome would not repair that result. No developer-effort reduction or observed human decision improvement was measured.

\section{Conclusion}

Cached atomic completion can be essential when validation and callback calls are charged. An action-wise potential yields an exact three-mode normal form, with all-budget supporting bases and a linear-size mixed-price cursor representation on compatible DAGs. Conditional actual-write correspondence and a source-derived snapshot application delimit the guarantees that reach native code.
