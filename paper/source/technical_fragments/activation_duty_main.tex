An initializer assigns the obligation present at activation; selecting any non-error state is insufficient.
\paragraph{An exact activation obligation.}\label{sec:cell-activation-duty}
Cell's owed-inspection bit starts at 1 exactly when $B$ holds the workpiece. Event $m_B$ sets it, $j$ clears it, and $m_A$ is forbidden while it is 1; other labels preserve it. Encoding 0 by $c$ and 1 by $d$ makes every monitor transition identical to this rule, including rejection of forbidden departure. Initialization and suffix induction prove exact enforcement. Figure~\ref{fig:cell-story}'s first path starts with debt and clears it by ordinary inspection; the second starts clear.

\paragraph{Invariants that begin at activation.}\label{sec:activation-scoped-main}
Activation-scoped interpretation ACT checks a pure invariant $\Box\varphi$ at the actual post-start observer vector and after every later label. It retains factual fluent values, not a past-violation bit. For deterministic observers with total update $d:V\times\Sigma\to V$, define
\[
 \operatorname{ACT}_\varphi(v)=\{w\mid\forall u\preceq w:\varphi(d^*(v,u))\},
\]
where prefixes include the empty word. A faithful safety monitor $M$ has non-error language $S_\varphi=\operatorname{ACT}_\varphi(v_0)$ from its initial state. Let $L_M(m)$ denote its continuations from state $m$.
\begin{proposition}[Safe lookup cells for pure invariants]\label{prop:lookup-act}
If a lookup at $v$ selects a non-error state $m$ reached together with $v$ by a safe word in the unrestricted monitor--observer product, or a state with the same continuation language, then $\varphi(v)$ holds and $L_M(m)=\operatorname{ACT}_\varphi(v)$.
\end{proposition}
\begin{proof}
Let $h$ reach the pair $(m_h,v)$. Faithfulness and non-error reachability give $h\in S_\varphi$, hence $\varphi(v)$. For every suffix $w$,
\[
 w\in L_M(m_h)\ \Longleftrightarrow\ hw\in S_\varphi
 \ \Longleftrightarrow\ w\in\operatorname{ACT}_\varphi(v).
\]
The second equivalence uses safety of the prefix $h$ and deterministic observers: future valuations depend only on $v$ and $w$. Language equivalence transfers the equality to $m$.
\end{proof}
The witness need not be plant-executable or obey one-shot update restrictions. This is residual-language reasoning~\cite{RosuHavelund2005Rewriting,FinkbeinerEtAl2022LiveSynthesis}, applied to the generated lookup. At activation, the adapter must choose the actual post-start key and use the same future observation rules; start is consumed once. Undefined entries and fallback initialization are outside the criterion. A true $\varphi(v)$ alone does not supply a lookup entry.

Independent source and table checks establish the criterion for 900 non-error cells in 138 saved tables (Technical Appendix~\ref{ta:lookup-act}). Applying it to a particular policy still requires those key and observation premises. PC2 and GSM below have direct arguments on reached tuples; the table checks do not validate all benchmark activations.
