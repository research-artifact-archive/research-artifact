# Publication provenance supplement

This supplement adds preparation/freeze provenance and reported historical evidence that was not all present in the frozen version-5 distribution. It changes no original scientific outcome. `../package/` remains byte-identical to its pre-publication snapshot.

`history/` preserves the following authored study directories: final DAG primitive evaluation, final native evaluation, original 87-input scale, 57-input hybrid scale, and its later checker. It also includes four prior input registries needed to inspect preparation overlap checks. Material also present in the frozen package is kept for an intelligible preparation history; duplicate files are not new evidence units.

The completion update additionally preserves:

- `primitive_scale_01/`: all 130 independent PRISM/AND-OR/packing units, including 37 timeouts, five failures, and four invalids. The earlier guard input registry was read for preparation overlap but was not bound by the historical scale manifest; publication does not repair that original limitation.
- `native_price_scale_01/` and `native_price_scale_supplement_01/`: all 432 original method units (413 successes/19 timeouts), and the separate 144-unit screened extension (140/four). The original less successful comparators remain.
- `primitive_rmw_02/`: 384 inputs and 2,688 budget comparisons under the earlier charged-acquisition contract, including all five counterexamples and their recorded states/actions.
- `adaptivity_gap_search_01/`: all 12,288 search records, the constructive-family proof, and 30 selected scalar checks. Search results are not population frequencies, and the selected checks are not an independent holdout.

Small authored dependencies are in `history/guaranteed_guards_01/`, `history/prism_guard_compact_01/`, and `earlier/quantitative_progress/adaptive_retry_control/`. The private raw assistant report is excluded; its author-side disposition remains and supplies no independent certification.

`PROVENANCE.json` lists every included file with its original relative path, original hash/size, public hash/size, and disposition. `EXACT_COPY` means byte equality. `LITERAL_WORKSTATION_PATH_PROJECTION` replaces the original session path, its research parent where needed, and author home by `${SESSION}`, `${RESTART_ROOT}`, and `${AUTHOR_HOME}`. Such files are derivative distribution records, not original preregistrations; embedded historical hashes still refer to the original files unless expressly described otherwise. Original private author-side raw reports, Python caches, and compiled class files are excluded with their hashes recorded. Authored source and class-hash receipts are available; JDK/PRISM runtime binaries and third-party articles/source copies are not redistributed.

The historical `generate.py`, `prepare.py`, `freeze.py`, and original run drivers make selection order and recorded provenance inspectable. They assume the old workspace layout and some projected receipt paths; they are not the public execution interface and should not be run in place. The public `package/reproduce*.py` entry points instead use the materialized, hash-bound inputs and write into new external output directories. The table aggregation command includes all supplied earlier scale outcomes without launching those original runs.

For native paths, `history/final_evaluation_dag_native_01/generate.py` contains the seeded vector construction, and `prepare.py` contains the success-before-failure path traversal, policy order, IDs, profiles, and first-path-only controls. The corresponding semantic generation grid is in `history/final_evaluation_dag_01/prepare.py`. The review package supports replay from these fixed inputs; it does not claim to reconstruct the historical clock times, original machine state, or all Java schedules.
