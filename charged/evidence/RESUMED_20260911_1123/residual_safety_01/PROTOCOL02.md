# Fixed online-implementation check02 (before results)

This is a new author implementation check after check01 and PROOF02. Its purpose is to test the two-heap state/update implementation and guard against an independent sorting oracle. It does not re-estimate scientific importance or certify the general proof. Results, source, all input manifests, traces and invalid inputs are retained; no unfavorable rerun is erased.

Exhaustive family: every completed weight tuple of lengths0..4 over{1,3,7}, every k0..|D|+2 and every integer ell0..Top_k(D). At every state query weights{1,2,3,6,7,8,50}. Compare prospective sum and fresh permission to sorting all completed weights plus the query. Then independently construct and check each allowed completing outcome fresh/match/mismatch, including heap partition, multiset, sum and count against the sorting oracle. Count rejected fresh actions separately. Invalid initial states ell=Top_k(D)+1 are required to reject. Queries must not mutate state. Every state/action row is saved to compressed JSONL.

Stream family: 240 fixed-seed streams (seed202609111146), length200 each. Start with completed prefix length instanceID mod11, weights drawn from{1,2,7,31,100,10000}, k chosen uniformly0..prefix_length+2 and ell uniformly0..Top_k(prefix). At each step choose the same weight alphabet and select uniformly among match,mismatch,and fresh if independently permitted. The independent sorting oracle checks every proposal and successor; record complete operation trace. This includes tied weights, credit beyond completed count, repeated promotions and insertions, and arbitrary future weight order. Stream states need only be valid residual states, not all reachable original histories.

Invalid argument controls: zero/negative/float/bool weights, negative/noninteger credit, negative/noninteger protected work, unknown mode, unsafe fresh. All rejections must preserve previously valid state. Timeout60seconds. Expected terminal status SUCCESS only if every discrepancy list is empty and every planned denominator completed. Startup writes protocol/implementation/checker/input hashes. No native latency, kernel transfer, independent blind review or W optimality is inferred.
