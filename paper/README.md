It has 18 pages through the Conclusion and 20 pages including Data Availability and references. `SNAPSHOT.json` records exact PDF/source hashes and the artifact evidence commit cited by the paper.

The revision clarifies the formal counted-work cap question, attribution of inherited DP/reflection/envelope results, native input/path selection, arithmetic complexity, and research AI use. Its Data Availability section points to the public evidence and reproducible examples. The 12 theorem/lemma/proposition statements and 12 proof blocks are unchanged from `../package/paper/main.tex`, as are reported scientific outcomes. The frozen pre-publication paper remains at that location.

To build locally, install an ACM `acmart` LaTeX environment with `pgfplots` and run `pdflatex -interaction=nonstopmode -halt-on-error main.tex` twice in a copy of this directory. The class hash used for the archived build is recorded; TeX installation differences and build timestamps can change PDF bytes. Class files and font/runtime installations are not redistributed.

It remains an author research draft, not a statement of acceptance or independent artifact certification.
