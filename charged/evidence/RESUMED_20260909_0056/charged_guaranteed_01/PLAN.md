# Charged guaranteed-operation exploration 01

Hypothesis: with distinct guaranteed guards and separable fixed API fees, the optimal complete primitive program from all-U may still equal a serial retry game after price transformation. This is an exploratory changed contract, not a rerun of the already refuted fallible-acquisition H-RMW hypothesis. Old primitive_rmw_02 counterexamples remain valid and unchanged. No application prevalence or wall-clock interpretation follows.

Each job has (w,p,g,v,r): unprotected opaque whole-kernel work w>0; own guarded-kernel premium p>=0; guaranteed acquisition fee g>=0; atomic conditional-commit fee v>=0 (same on success/failure); release or guarded-commit fee r>=0. Retaining other guards has no additional charge and does not protect the selected job. Initial guards are distinct, absent and unprepared. Each foreground job must commit after its predecessors, using immutable captured outputs. Costs describe an abstract resource metric; no native API calibration is asserted.

Operations: U->C for w (ready only); U->L for g (before readiness allowed); C->D normally or C->U after one invalidation for v; C->LC normally or C->L after one invalidation for g; L->LC for w+p (ready only); L->U or LC->C release for r; LC->D for r; C->U and LC->L discard for zero. Fresh atomic callback U->D costs g+w+p+r. Cached callback C->D costs g+r on match, g+w+p+r after one invalidation. No batch fee discounts and no fallible acquisition. C and LC jobs must already be physically ready; D forms an ideal. Free inspection does not improve control in this oracle-free abstract interface and is omitted as a self-loop. Noncompletion costs infinity.

Serial macro prices: a=c=w+v; excess premium p_eff=g+p+r-v. We restrict p_eff>=0 so this comparison uses the published nonnegative-premium recurrence without modifying it. Guaranteed acquisition cannot fail. Upper bound is executable by serial macros. Falsifier: any primitive optimal root strictly below the macro value, or any disagreement between two independent semantic checks. Retain all inputs/results and full first discrepant graph and policy; do not interpret Bellman ties without a termination witness.

Before run: materialize exhaustive n=1,2 price vectors from 12 explicit templates, both 2-job forward DAGs, budgets 0..4; additionally 192 seeded n=3/4 cases with forward-edge DAGs and templates, plus the published 4-job k=1 example with all fees zero. Every materialized input is one denominator unit. Max 3 seconds per unit, 180 seconds campaign, mandatory stop September9 10JST. Record SUCCESS/FAILURE/TIMEOUT/INVALID/NOT_RUN without exclusion/retry. Distinguish a scientifically refuted equality from execution failure; a correct solver execution can find a gap. Validate every state Bellman equation and selected-policy decreasing rank with a fresh graph traversal. This test cannot establish a universal theorem; if no gaps appear, derive proof conditions and independently probe omitted operations.

## Analytic preflight before materialization/execution
The writer noticed that p_eff>=0 alone need not make w+v the no-interference optimum: for (w,p,g,v,r)=(1,2,0,1,0), prepare then acquire/commit costs 1, while the naive serial baseline costs 2. Therefore broad equality is already analytically suspect before numerical outcomes. Preserve the registered exploration to expose other patterns, and separately report the pre-result dominance stratum v<=g+r. This is a planned secondary diagnostic, not held-out confirmation or a replacement of the broad denominator. A corrected normal form needs to include or dominate alternative validation routes.
