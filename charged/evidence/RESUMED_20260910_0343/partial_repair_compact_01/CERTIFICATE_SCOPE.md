# Certificate scope and lower-bound quantifiers

These clarifications follow a read-only author-side theoretical check after the recorded studies. They change no algorithm, proof claim, outcome or certificate byte and are not an independent blind review.

The adversarial lower path certifies the competitive objective with quantifiers: for every deterministic stopping policy P there exists a write budget B and a matching environment giving ratio at least R. If P stops at a prefix of the path, the witness uses the minimum consistent budget for that prefix. It does not fix one common budget equal to the entire q-step path cost for every P. For three unit components, q=3,mu=2, the path with costs(1,1,3) gives stopping-prefix budgets1,2,5 and ratios3/2,3/2,5/3. Fixing B=5 for all policies would give ratio1 at the first prefix and would not prove the same lower bound. The original minimum-consistent-budget argument supplies the required per-policy witness.

Both certificate checkers assume a correct profile H supplied for the source footprint/weight instance. They verify H/G consistency and the upper/lower paths, not that H is a maximum over all attainable footprint unions. For two unit singleton components,q=2,mu=1, the incorrect H=G=[0,1,1] can admit a ratio1 profile certificate, whereas the true H=G=[0,1,2] has optimum3/2. Therefore a profile-relative certificate is not an input-relative certificate for arbitrary footprints. The preserved geometry generator explicitly enumerates all reachable unions for small studies. The singleton study analyses independently regenerate the sorted weights, component order and complete prefix-sum profile before checking a certificate. The public example likewise constructs its singleton profile from the input weights. General-footprint profile validation remains part of the stated input obligation and can be expensive.

The returned paths certify the declared deterministic partial-repair competitive objective. They do not certify a native program's semantic conformance, publication-cost calibration, randomized optimality or a budgetwise simultaneous optimum.
