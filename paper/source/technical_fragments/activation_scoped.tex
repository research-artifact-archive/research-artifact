\paragraph{Obligations that begin at activation.}
\label{sec:activation-scoped}
Activation-scoped interpretation ACT starts a pure invariant with the actual post-boundary observer vector. It retains factual fluent values, without a past-violation bit, and consumes start once. The following proposition gives one complete criterion: a matching safe reference residual is exact even when the actual history violated the invariant before activation. This differs from A's safe-history restriction and H's whole-past obligation. Section~\ref{sec:pc2-case} checks ACT for the thirteen invariants along the saved PC2 policy; the 138 A checks remain A checks.

\subsection{From a Safe Lookup Cell to an Activation-Scoped Invariant}
\label{ta:lookup-act}
The following proposition gives the complete statement and proof for the lookup criterion in main-paper Section~\ref{sec:monitor-meaning}. A faithful invariant monitor reached safely with observer vector $v$ accepts exactly $\operatorname{ACT}_\varphi(v)$. The witness may come from the unrestricted monitor--observer product; physical executability of that reference history is unnecessary. We first check the constructed lookup, then compare its monitors with source formulas, and finally identify the conditions required at actual activations. Main-paper Table~\ref{tab:guarantee-routes} maps the guarantees; Table~\ref{tab:validation-populations} in Appendix~\ref{ta:validation_scope} gives detailed validation populations.

\paragraph{Reconstructing the frontend lookup.}
The nine inherited inputs have 46 NEW requirement positions and three variants, yielding 138 occurrences. The saved independent reconstruction checks all 138 lookup tables and 1,587 entries, including 900 non-error entries, 687 error entries, 408 observer columns and 31,176 observer transitions. S4.2 gives the export protocol and reconstruction checks. A non-error entry is chosen from a pair reached by a finite safe word of the free monitor--observer product; equivalent-state alternatives must have the same error language. The reconstruction explores non-error successors, so induction on its search depth supplies that witness. The saved table records $(v,m)$, not the witness word itself.

\paragraph{Matching monitors to source invariants.}
The reconstruction establishes safe lookup reachability. To check the proposition's separate faithfulness premise, we compare the saved monitors with the original source invariants independently of the Java formula compiler. All 46 NEW positions are pure invariants $\Box\varphi$: seven use declared fluents only, six use action predicates only, and 33 use both. Names such as Pending and SEQUENTIAL designate deterministic current-value observers, not additional temporal operators. A restricted parser reads propositional negation, conjunction, disjunction and implication inside $\Box$, assertion aliases, fluent initial values, event-set aliases/differences and finite indexed ranges. Unsupported syntax is rejected. Source-defined observer rules must match the saved rules, including action predicates' last-event convention.

For each invariant, the finite check verifies $\varphi(v_0)$ and a non-error initial monitor state, then explores every non-error monitor--observer pair. At each pair $(m,v)$ and every checked label $a$, it verifies
\[
 \delta_M(m,a)\in\mathsf{Error}
 \quad\Longleftrightarrow\quad
 \neg\varphi(d(v,a)).
\]
The checked alphabet contains every saved observer label and every source-referenced event, plus a fresh representative for all unmentioned events. The latter class has the same source-observer effect (declared fluents stutter and action predicates reset); the saved DFA uses its default transition. From the initial pair, induction on word length now proves that a prefix is non-error exactly when all its source valuations satisfy $\varphi$. Thus this finite condition establishes the monitor-faithfulness premise used above on these alphabets; it is not an assumption that a passing table check alone validates the compiler.

All 138 occurrences pass: 900 non-error product pairs, 35,283 pair/label checks, and all 900 non-error lookup cells contained in the safe product. There are no unsupported formulas or mismatches. The three variants agree on source formula, observers and monitor for each of the 46 positions; the counts are occurrences, not 138 independent formulas. This establishes ACT exactness for those lookup cells under their reference observation semantics.

\paragraph{What this yields for a winning policy.}
At a real activation, the installed state must have the ACT language for the actual post-start observer vector. Using that vector in the lookup with the same future observation rules is sufficient; Appendix~\ref{ta:command-observation} gives a further sufficient case for command-preserved observers. Start is accounted for once, before initialization, rather than observed twice. Every active suffix of a winning policy is accepted by the installed monitor; the proposition therefore gives the invariant at activation and after every observed prefix. A previous actual violation is irrelevant to this explicitly start-scoped requirement. This is not the history-inclusive H interpretation, nor does it turn an arbitrary A inclusion into ACT exactness. An undefined/rejected lookup or a separate fallback initializer is outside this argument. Conversely, $\varphi(v)$ alone does not ensure that the table has a non-error entry for $v$.
