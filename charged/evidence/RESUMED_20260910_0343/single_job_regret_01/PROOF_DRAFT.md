# Single-job regret derivation for the pre-comparison whole-kernel interface

Let C_P(B) be worst C over environments with at most B writes. Define R*=inf_P sup_{B≥0}(C_P(B)−C*(B)), where P receives no B and has Q≤r+1 universally. Assume n=1, w>0, κ≥0, deterministic causal policies, the whole-kernel Table1 operations and finite-write termination.

Informed comparator: if B≤r, B+1 cheap attempts attain (B+1)κ and immediate fresh preparation/cached completion attains κ+w (at B=0 the latter actually costsκ). For a lower bound put a fresh own-key write immediately before each cheap comparison until B such writes have been spent. If any completing call is chosen before exhaustion, invalidate its cached comparison if necessary, using at most one write per previous failure plus that mismatch, to force w. A fresh completion already paysw. Otherwise a matching cheap call after B failures pays at least(B+1)κ. For B>r, the same per-comparison adversary up to the call cap forcesw and at least one call. Hence C*(B)=κ+min(Bκ,w) for B≤r and κ+w for B>r. This proof considers a different finite adversary execution depending on the program's next operation; it does not add an impossible write after exhausting B.

Unaware lower bound: κ≥w or r=0 needs only nonnegativity. For0<κ<w and r≥1, follow a minimum-write run: no writes until just before each selected counted comparison, then one fresh own-key write. No cheap call completes on this run. Let t be the number of cheap failures before a completing call, so t≤r. If the first such completion is fresh, stop after t actual writes. Cost is(t+1)κ+w and the informed cost at B=t isκ+min(tκ,w), yielding regret at leastw. If it is cached and t<r, invalidate it with one more write, setting B=t+1≤r. The regret is tκ+w−min((t+1)κ,w), at leastw−κ. If cached and t=r, useB=r+1, yielding regret rκ. Thus every program has regret at leastmin(w−κ,rκ). Extra counted calls/work can only strengthen the lower bound. Free inspections may see old writes, but fresh identities immediately before each comparison invalidate all retained preparations. Programs cannot keep protection or finish outside the listed completing operations. They must eventually choose a completing operation on this finite prefix because exceedingr failures violates the universal cap.

Upper bounds: always-cached has C(0)=κ and C(B)=κ+w forB≥1, so its regret is max(w−κ,0) when r≥1, and0 when r=0. Threshold r has C(B)=κ+κmin(B,r)+w·1[B>r]. ForB≤r the regret is max(Bκ−w,0)≤rκ, and forB>r it equalsrκ. Thus R*=min(max(w−κ,0),rκ), choosing the better of these policies. The κ=0 case has regret0 via threshold r. This is an all-budget additive criterion for one job, not a claim about arbitrary workflows, randomization or empirical performance.

Potential issue requiring author-side checking: the informed comparator adversary must branch to a mismatch while write budget remains; if the program spends counted validation-only calls lacking a usable preparation, the cap/cost argument must count these without assuming each has caused a write. The lower bound may restrict to a minimum-write prefix that invalidates every usable comparison while such calls only addκ. Gratuitous preparation affects neither Q norC but does not invalidate the adversary construction.
