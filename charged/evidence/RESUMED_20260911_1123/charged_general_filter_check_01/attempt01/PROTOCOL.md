## Independent sorting oracle

Maintain dictionaries future_h and completed_q separately. Top_k is literally sum(sorted(entries, reverse=True)[:k]). For a proposed unfinished i, build X = completed_q values + every other unfinished fee, then compute cached=Top_k(X), fresh=Top_k(X+[h_i+p_i])-p_i. Viability is incurred <= Top_k(completed_q values + all future fees). Do not use tau/sigma or the draft's root-query algebra. On completion move h_i+p_i to completed_q; add p_i for fresh, zero for cached match, h_i+p_i and one k for cached mismatch.
